என் தாய்மொழி பிரெஞ்சு; ஆனால் என் மென்பொருள் வேலையில் பெரும்பகுதி — commit செய்திகள், குறியீட்டுக் குறிப்புரைகள், GitHub issues, பன்னாட்டுக் குழுக்களுடன் அரட்டை, ஆவணங்கள் — ஆங்கிலத்திலேயே நடக்கிறது. சரளமான ஆங்கிலத்தில் தட்டச்சு செய்வது கடினமல்ல; மூளையின் மற்ற பகுதி தாய்மொழியில் இயங்கிக்கொண்டிருக்கும்போது ஆங்கிலத்தில் *சிந்திப்பதுதான்* உண்மையான தடை. நீங்களே மொழிபெயர்க்க வேண்டிய அவசியம் இல்லையென்றால், டிக்டேஷன் அந்தத் தடையை முழுவதுமாக நீக்கிவிடுகிறது.

## அமைப்பு

நான் opons-voxd-ஐ இரண்டு தனித்தனி push-to-talk ஹாட்கீகளுடன் பயன்படுத்துகிறேன்:

- **`Ctrl+Alt+W` — வழக்கமான டிக்டேஷன்.** அதை அழுத்திப் பிடித்து, பிரெஞ்சில் பேசி, விட்டதும் கர்சரில் பிரெஞ்சு உரை தட்டச்சு ஆகிறது. குறிப்புகள், பிரெஞ்சு சக ஊழியர்களுடன் அரட்டை என பிரெஞ்சிலேயே இருக்க வேண்டிய எல்லாவற்றுக்கும்.
- **`Ctrl+Alt+K` — டிக்டேஷனுடன் மொழிபெயர்ப்பு.** அதே செய்கை, ஆனால் நான் பிரெஞ்சில் பேச, கர்சரில் *ஆங்கிலம்* வருகிறது. ஆங்கில வாசகர்களுக்கான எல்லாவற்றுக்கும்: commit செய்திகள், PR விளக்கங்கள், குறியீட்டுக் குறிப்புரைகள், GitHub issues, ஆங்கில அரட்டை சேனல்கள்.

மொழிபெயர்ப்புக் கருவியில் நகலெடுத்து ஒட்டுவது இல்லை, வேறு சாளரத்துக்குத் தாவுவது இல்லை, மீண்டும் தட்டச்சு செய்வதும் இல்லை. நான் பேசுகிறேன்; கர்சர் ஏற்கெனவே இருக்கும் இடத்திலேயே ஆங்கிலம் தோன்றுகிறது.

## ஏன் இரண்டு ஹாட்கீகள், ஒன்று அல்ல

அந்தப் பணிக்கென உண்மையிலேயே பயிற்றுவிக்கப்பட்ட மாடலுடன் மட்டுமே மொழிபெயர்ப்பு நன்றாக அமையும். அன்றாட பிரெஞ்சு ஹாட்கீக்கு `large-v3-turbo`-ஐப் பயன்படுத்துகிறேன், ஏனெனில் அது வேகமானது — ஆனால் அதன் மொழிபெயர்ப்புத் தரம் மோசம்; அது மொழிபெயர்ப்புக்காக அல்ல, படியெடுப்பு வேகத்துக்காக மேம்படுத்தப்பட்டது. மொழிபெயர்ப்பு ஹாட்கீயோ, சரியாக மொழிபெயர்க்கும் இரண்டாவது மாடலை (`medium`) ஏற்றுகிறது. இரண்டு மாடல்களும் ஒரே நேரத்தில் GPU நினைவகத்தில் இருக்கின்றன; சில GB-க்கு மேல் இடம் மிச்சமுள்ள கார்டில் இந்தக் கூடுதல் செலவு ஒரு பொருட்டே அல்ல. உள்ளூர் AI பணி ஒன்றுக்கு அந்த நினைவகம் எனக்குத் திரும்பத் தேவைப்படும்போது, அந்தப் பணியை இயக்கும் ஏஜென்ட் opons-voxd-இன் MCP சர்வர் வழியாக இரண்டு மாடல்களையும் இறக்கி, பிறகு மீண்டும் ஏற்றுகிறது; இடையில் ட்ரே ஐகான் குறுக்குக் கோடிட்ட சாம்பல் வளையமாக மாறுவதால், டிக்டேஷன் முடக்கப்பட்டிருப்பது எனக்குத் தெரியும் ([உள்ளூர் AI-க்காக GPU-ஐ விடுவித்தல்](README.ta.md#உள்ளூர்-ai-க்காக-gpu-ஐ-விடுவித்தல்-mcp-சர்வர்) பார்க்கவும்).

## முயன்று பாருங்கள்

இது opons-voxd-இன் வழக்கமான உள்ளமைவுதான் — fork-ஓ patch-ஓ தேவையில்லை. `OPONS_VOXD_PTT_HOTKEY`, `OPONS_VOXD_PTT_TRANSLATE_HOTKEY`, `OPONS_VOXD_TRANSLATE_MODEL`, `OPONS_VOXD_LANGUAGE` பற்றி அறிய, முதன்மை README-இல் உள்ள [Configuration](../README.md#configuration), [Push-to-talk-and-translate hotkey](../README.md#push-to-talk-and-translate-hotkey) பகுதிகளைப் பார்க்கவும்.

நீங்கள் அன்றாடம் ஆங்கிலம் அல்லாத வேறொரு மொழியைப் பேசி, வேலையை ஆங்கிலத்தில் செய்பவர் என்றால், இந்தத் திட்டத்தின் மிகப் பயனுள்ள அம்சம் பெரும்பாலும் இதுவாகத்தான் இருக்கும்.
