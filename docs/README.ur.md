# opons-voxd

> نوٹ: opons-voxd کا jakovius/voxd سے کوئی تعلق نہیں۔ یہ نام آزادانہ طور پر چنا گیا — `opons` = O. Pons (مصنف)، `voxd` = vox + daemon (لاطینی/Unix روایت)۔

> **⚠ پچھلے ورژنز سے مطابقت جان بوجھ کر ختم کی گئی ہے۔** یہ پروجیکٹ پہلے `voice_in_linux` کہلاتا تھا۔ نام کی تبدیلی سے بائنری کا نام، سورس فائل کا نام اور ہر انوائرنمنٹ ویری ایبل (`VOICE_IN_*` → `OPONS_VOXD_*`) بدل گئے ہیں، اور رن ٹائم پر `xdotool` کی ضرورت بھی ختم ہو گئی ہے (اب اس کی جگہ `libxtst-dev` کے ذریعے براہِ راست XTest سے ان پٹ بنایا جاتا ہے)۔ نہ کوئی alias، نہ کوئی عبوری مدت — اپنی لانچ اسکرپٹس، آٹو اسٹارٹ اندراجات اور `apt install` والی سطریں اپ ڈیٹ کر لیں۔

**Linux کے لیے لوکل اسپیچ ٹو ٹیکسٹ ڈکٹیشن — آپ کی آواز کبھی آپ کی مشین سے باہر نہیں جاتی۔**

## کیوں؟

میں چاہتا تھا کہ Linux پر کسی بھی ایپلیکیشن میں بول کر متن لکھ سکوں، اور اپنی آواز کسی تیسرے فریق کے سرور کو نہ بھیجوں۔ مجھے جتنے بھی حل ملے — براؤزر ایکسٹینشنز، کلاؤڈ API، SaaS پلیٹ فارمز — سب ٹرانسکرپشن کے لیے آپ کی آڈیو دور کے سرورز پر اسٹریم کرتے ہیں۔ یعنی آپ کا بولا ہوا ہر لفظ انٹرنیٹ سے گزرتا ہے: ای میلز، خفیہ دستاویزات، کلائنٹس کا ڈیٹا، ذاتی نوٹس — سب کچھ۔

یہ پروجیکٹ ایک ہلکا پھلکا، مکمل طور پر لوکل متبادل ہے۔ یہ پوری طرح آپ کی مشین پر [whisper.cpp](https://github.com/ggerganov/whisper.cpp) کے ذریعے چلتا ہے؛ whisper.cpp دراصل Whisper کا ایک لوکل رن ٹائم ہے، اور Whisper، OpenAI کا اوپن سورس اسپیچ ریکگنیشن ماڈل ہے۔ ابتدائی سیٹ اپ کے بعد کسی نیٹ ورک کنکشن کی ضرورت نہیں رہتی۔ کوئی ڈیٹا کبھی آپ کے کمپیوٹر سے باہر نہیں جاتا۔

اسے AI کی مدد سے بنایا گیا ہے۔

## یہ کیسے کام کرتا ہے

ڈکٹیشن کے دو طریقے، دونوں بیک وقت دستیاب۔

### ٹرے آئیکن موڈ — ایک کلک سے آن/آف، متن کلپ بورڈ پر

1. آپ کی سسٹم ٹرے میں ایک چھوٹا آئیکن نظر آتا ہے
2. **بایاں کلک** → ریکارڈنگ شروع (آئیکن سرخ ہو جاتا ہے)
3. **دوبارہ بایاں کلک** → ریکارڈنگ رک جاتی ہے، Whisper آپ کی مشین پر ہی آڈیو کو ٹرانسکرائب کرتا ہے
4. ٹرانسکرائب شدہ متن خود بخود آپ کے کلپ بورڈ پر کاپی ہو جاتا ہے (X11 کے دونوں سلیکشنز میں)
5. ایک ڈیسک ٹاپ نوٹیفکیشن متن کو 10 سیکنڈ تک دکھاتا ہے
6. `Ctrl+Shift+V`، `Shift+Insert` یا مڈل کلک سے کہیں بھی پیسٹ کریں

آئیکن پر **دایاں کلک** کرنے سے ایک مینو کھلتا ہے: Toggle / Unload models / Reload models / Quit (دیکھیں [لوکل AI کے لیے GPU خالی کرنا](#لوکل-ai-کے-لیے-gpu-خالی-کرنا-mcp-سرور))۔

### Push-to-talk موڈ — ہاٹ کی دبائے رکھنا، کرسر پر ٹائپنگ

1. **`Ctrl+Shift+Space` دبائے رکھیں** → ریکارڈنگ شروع (آئیکن سرخ ہو جاتا ہے)
2. **کیز چھوڑ دیں** → ریکارڈنگ رک جاتی ہے، آڈیو ٹرانسکرائب ہوتی ہے
3. ٹرانسکرائب شدہ متن **سیدھا کی بورڈ کرسر پر ٹائپ ہو جاتا ہے** (X11 کی XTest ایکسٹینشن کے ذریعے)، اسی ونڈو میں جس پر فوکس ہو

ہاٹ کی `OPONS_VOXD_PTT_HOTKEY` سے بدلی جا سکتی ہے۔ ایک دوسری، آزاد ہاٹ کی (`OPONS_VOXD_PTT_TRANSLATE_HOTKEY`، ڈیفالٹ `ctrl+alt+t`) اسی طرح کام کرتی ہے، مگر ٹرانسکرپٹ کے بجائے انگریزی ترجمہ ٹائپ کرتی ہے — دیکھیں [مرکزی README](../README.md#push-to-talk-and-translate-hotkey)۔

## خصوصیات

- **100% لوکل** — آڈیو آپ کے CPU یا GPU پر پروسیس ہوتی ہے، کہیں نہیں بھیجی جاتی
- **GPU ایکسلریشن** — تقریباً فوری ٹرانسکرپشن کے لیے NVIDIA CUDA سپورٹ
- **99 زبانیں** — OpenAI Whisper کی بدولت
- **ہلکا پھلکا** — سادہ C، کوئی Python نہیں: ڈیمن، اور ساتھ میں ایک اختیاری 25 KB کا MCP سرور جو صرف libc سے لنک ہوتا ہے
- **سسٹم ٹرے انضمام** — ٹاسک بار میں ایک چھوٹا سا آئیکن جو کام میں رکاوٹ نہیں بنتا
- **Push-to-talk ہاٹ کی** — ریکارڈ کرنے کے لیے `Ctrl+Shift+Space` (قابلِ ترتیب) دبائے رکھیں، چھوڑتے ہی ٹرانسکرپٹ کی بورڈ کرسر پر ٹائپ ہو جاتا ہے
- **Push-to-talk-اور-ترجمہ ہاٹ کی** — ایک دوسری ہاٹ کی، جسے الگ سے ترتیب دیا جا سکتا ہے اور جو لفظ بہ لفظ ٹرانسکرپٹ کے بجائے آپ کی بات کا انگریزی ترجمہ ٹائپ کرتی ہے
- **دوہرا کلپ بورڈ** — متن X11 کے PRIMARY اور CLIPBOARD، دونوں سلیکشنز میں جاتا ہے
- **ڈیسک ٹاپ نوٹیفکیشنز** — ٹرانسکرائب شدہ متن نوٹیفکیشن میں دکھایا جاتا ہے
- **صوتی کمانڈز** — `commands/` میں ہر زبان کے لیے ایک کمانڈ فائل، ڈیفالٹ طور پر بند (`OPONS_VOXD_COMMANDS=1`)۔ نئی زبان شامل کرنے کے لیے `commands/xx.txt` بنائیں، دوبارہ کمپائل کرنے کی ضرورت نہیں۔
- **عارضی نوٹیفکیشنز** — ڈیفالٹ طور پر نوٹیفکیشنز ظاہر ہو کر پھر پوری طرح غائب ہو جاتے ہیں۔ `OPONS_VOXD_NOTIFY_PERSIST=1` انہیں ہسٹری میں محفوظ رکھتا ہے۔
- **نوٹیفکیشن موڈ** — `OPONS_VOXD_NOTIFY=normal|quiet|silent|off` کامیابی کے نوٹیفکیشنز کو کنٹرول کرتا ہے (ڈیفالٹ `quiet`: ببل، بغیر آواز)۔ غلطیاں ہمیشہ آواز کے ساتھ دکھائی جاتی ہیں، ہر موڈ میں، بلا استثنا۔ مکمل جدول مرکزی README میں ہے۔
- **خودکار کیپیٹلائزیشن** — جملوں کا پہلا حرف خود بخود کیپیٹل ہو جاتا ہے
- **ضرورت پر GPU خالی کرنا** — Whisper ماڈل VRAM سے ان لوڈ کریں (ٹرے مینو سے، یا بلٹ اِن MCP سرور کے ذریعے کسی بھی AI ایجنٹ سے) اور کام ختم ہونے پر دوبارہ لوڈ کریں
- **آٹو اسٹارٹ** — لاگ اِن پر خود بخود شروع ہونے کے لیے ترتیب دیا جا سکتا ہے

### NVIDIA GPU (اختیاری، مگر کارکردگی کے لیے انتہائی اہم)

CUDA کے بغیر، 15 سیکنڈ کی گفتگو کے لیے **10 سے 15 سیکنڈ** کی پروسیسنگ متوقع رکھیں۔ CUDA کے ساتھ، **1 سیکنڈ سے بھی کم**۔ یعنی **10 سے 50 گنا** تیز۔

| جزو | کم از کم | جانچ |
|---|---|---|
| NVIDIA ڈرائیور | 570+ | `nvidia-smi` |
| CUDA Toolkit | 12.0+ | `nvcc --version` |

اگر `nvidia-smi` چلتا ہے مگر `nvcc` نہیں، تو CUDA ٹول کٹ انسٹال کریں:

```bash
sudo apt install nvidia-cuda-toolkit
```

اگر `nvidia-smi` میں دکھایا گیا CUDA ورژن `nvcc` کے بتائے ہوئے ورژن سے **کم** ہو، تو ڈرائیور اپ ڈیٹ کریں:

```bash
ubuntu-drivers devices
sudo apt install nvidia-driver-590
sudo reboot
```

```bash
./opons-voxd
```

## لوکل AI کے لیے GPU خالی کرنا (MCP سرور)

Whisper ماڈل ہر وقت GPU میموری میں رہتے ہیں (`large-v3-turbo` + `medium` کے لیے تقریباً 3.8 GB)۔ جب آپ کو یہ VRAM کسی اور کام کے لیے چاہیے — کوئی لوکل LLM، کوئی امیج ماڈل، کوئی ٹریننگ رن — تو opons-voxd خود بند ہوئے بغیر انہیں ان لوڈ کر سکتا ہے اور بعد میں دوبارہ لوڈ کر سکتا ہے۔ ان لوڈ کرنے سے پروسیس کا CUDA کانٹیکسٹ بھی ختم ہو جاتا ہے، اس لیے opons-voxd `nvidia-smi` سے مکمل طور پر غائب ہو جاتا ہے (0 MB VRAM)۔ اگر ماڈل فائلیں ابھی پیج کیش میں ہوں تو دوبارہ لوڈ ہونے میں ایک سیکنڈ سے کم لگتا ہے، ورنہ چند سیکنڈ۔

**ٹرے آئیکن کی حالتیں:**

| آئیکن | حالت |
|:---:|---|
| سفید حلقہ | ماڈل لوڈ، تیار |
| سرخ ٹھوس دائرہ | ریکارڈنگ |
| نارنجی ٹھوس دائرہ | ٹرانسکرپشن جاری |
| ترچھی لکیر والا سرمئی حلقہ (⊘) | ماڈل ان لوڈ، GPU میموری خالی، ڈکٹیشن بند |
| نیلی تین چوتھائی قوس | ماڈل دوبارہ لوڈ ہو رہے ہیں |

ماڈل ان لوڈ ہوں تو آئیکن پر کلک کرنے یا push-to-talk ہاٹ کی دبانے پر ریکارڈنگ کے بجائے غلطی کا نوٹیفکیشن دکھائی دیتا ہے۔

**ہاتھ سے:** ٹرے آئیکن پر دایاں کلک > *Unload models (free GPU memory)* (ماڈل ان لوڈ کر کے GPU میموری خالی کرنا)، پھر *Reload models* (ماڈل دوبارہ لوڈ کرنا)۔

**AI ایجنٹ سے (MCP):** ڈیمن کو `-m` / `--mcp` کے ساتھ شروع کریں (ڈیفالٹ طور پر بند)۔ `make` ساتھ ہی `opons-voxd-mcp` بھی بناتا ہے: stdio پر چلنے والا ایک [Model Context Protocol](https://modelcontextprotocol.io) سرور، جو صرف libc سے لنک ہوتا ہے (تقریباً 1.5 MB RAM)۔ یہ تین ٹولز فراہم کرتا ہے: `unload_models`، `reload_models` اور `get_status`۔ Claude Code کے ساتھ:

```bash
claude mcp add --scope user opons-voxd -- /path/to/opons-voxd/opons-voxd-mcp
```

زیادہ تر دوسرے کلائنٹس (Claude Desktop، Cursor، LM Studio...) یہ JSON استعمال کرتے ہیں:

```json
{ "mcpServers": { "opons-voxd": { "command": "/path/to/opons-voxd/opons-voxd-mcp" } } }
```

مکمل تفصیل [مرکزی README](../README.md#free-the-gpu-for-local-ai-mcp-server) میں۔

## Push-to-talk ہاٹ کی

ساتھ آنے والی `launch.sh` فائل `ctrl+alt+w` (AZERTY کے لیے تجویز کردہ) یا `ctrl+alt+z` (QWERTY کے لیے تجویز کردہ) استعمال کرتی ہے۔ یہ کی `A` کے بالکل ساتھ ہے، اس لیے پورا امتزاج صرف بائیں ہاتھ سے دبایا جا سکتا ہے (چھنگلی `Ctrl` پر، انگوٹھا `Alt` پر، انگشتِ حلقہ یا درمیانی انگلی `W`/`Z` پر)۔ ٹائپنگ کا انداز نہیں بگڑتا، اور زیادہ تر ڈیسک ٹاپ انوائرنمنٹس میں یہ امتزاج ڈیفالٹ طور پر کسی اور کام کے لیے مختص نہیں ہوتا۔ اسے `OPONS_VOXD_PTT_HOTKEY` سے ترتیب دیں۔ مکمل تفصیل [مرکزی README](../README.md#push-to-talk-hotkey) میں۔
