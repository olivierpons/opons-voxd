माझी मातृभाषा फ्रेंच आहे, पण माझं बहुतांश सॉफ्टवेअरचं काम — कमिट मेसेज, कोड कमेंट्स, GitHub issues, आंतरराष्ट्रीय टीम्सशी चॅट, डॉक्युमेंटेशन — इंग्रजीत होतं. अस्खलित इंग्रजी टाइप करणं अवघड नाही; खरी अडचण आहे इंग्रजीत *विचार* करणं, तेही मेंदूचा बाकीचा भाग मातृभाषेत चालू असताना. स्वतः भाषांतर करावं लागलं नाही, तर डिक्टेशन ही अडचण पूर्णपणे दूर करतं.

## सेटअप

मी opons-voxd दोन स्वतंत्र push-to-talk हॉटकीसह वापरतो:

- **`Ctrl+Alt+W` — साधं डिक्टेशन.** हॉटकी दाबून ठेवतो, फ्रेंचमध्ये बोलतो, सोडतो, आणि कर्सरवर फ्रेंच मजकूर टाइप होतो. नोट्स, फ्रेंच सहकाऱ्यांशी चॅट आणि फ्रेंचमध्येच राहणाऱ्या प्रत्येक गोष्टीसाठी.
- **`Ctrl+Alt+K` — डिक्टेशन आणि भाषांतर.** तीच कृती, पण मी फ्रेंचमध्ये बोलतो आणि कर्सरवर *इंग्रजी* येतं. इंग्रजीत वाचल्या जाणाऱ्या प्रत्येक गोष्टीसाठी: कमिट मेसेज, PR वर्णनं, कोड कमेंट्स, GitHub issues, इंग्रजी चॅट चॅनेल्स.

भाषांतराच्या टूलमध्ये कॉपी-पेस्ट नाही, कॉन्टेक्स्ट स्विच नाही, पुन्हा टाइप करणं नाही. मी बोलतो, आणि माझा कर्सर जिथे आधीच आहे तिथेच इंग्रजी उमटतं.

## दोन हॉटकी का, एक का नाही

भाषांतर तेव्हाच चांगलं होतं, जेव्हा मॉडेल खरोखर त्याच कामासाठी प्रशिक्षित असतं. रोजच्या फ्रेंच हॉटकीसाठी मी `large-v3-turbo` वापरतो, कारण ते वेगवान आहे — पण त्याचं भाषांतर कमकुवत आहे, कारण ते ट्रान्सक्रिप्शनच्या वेगासाठी ऑप्टिमाइझ केलेलं आहे, भाषांतरासाठी नाही. म्हणून भाषांतराची हॉटकी दुसरं मॉडेल (`medium`) लोड करते, जे नीट भाषांतर करतं. दोन्ही मॉडेल्स एकाच वेळी GPU मेमरीत राहतात; काही GB पेक्षा जास्त जागा मोकळी असलेल्या कार्डवर हा जादा भार नगण्य आहे. एखाद्या लोकल AI कामासाठी मला ती मेमरी परत हवी असते, तेव्हा ते काम चालवणारा एजंट opons-voxd च्या MCP सर्व्हरद्वारे दोन्ही मॉडेल्स अनलोड करतो आणि नंतर पुन्हा लोड करतो; त्या दरम्यान ट्रे आयकॉन तिरकी रेघ असलेल्या राखाडी वलयात बदलतो, त्यामुळे डिक्टेशन बंद आहे हे मला कळतं ([लोकल AI साठी GPU मोकळा करणे](README.mr.md#लोकल-ai-साठी-gpu-मोकळा-करणे-mcp-सर्व्हर) पाहा).

## करून बघा

हे opons-voxd चं नेहमीचं कॉन्फिगरेशन आहे — ना फोर्क लागतो, ना पॅच. `OPONS_VOXD_PTT_HOTKEY`, `OPONS_VOXD_PTT_TRANSLATE_HOTKEY`, `OPONS_VOXD_TRANSLATE_MODEL` आणि `OPONS_VOXD_LANGUAGE` यांच्यासाठी इंग्रजीतल्या मुख्य README मधले [Configuration](../README.md#configuration) आणि [Push-to-talk-and-translate hotkey](../README.md#push-to-talk-and-translate-hotkey) हे विभाग पाहा.

तुम्ही रोज इंग्रजीखेरीज दुसरी भाषा बोलत असाल, पण काम इंग्रजीत करत असाल, तर या प्रोजेक्टमधलं सगळ्यात उपयोगी फीचर बहुधा हेच आहे.
