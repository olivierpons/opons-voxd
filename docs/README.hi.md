# opons-voxd

> नोट: opons-voxd का jakovius/voxd से कोई संबंध नहीं है। यह नाम स्वतंत्र रूप से चुना गया — `opons` = O. Pons (लेखक), `voxd` = vox + daemon (लैटिन/Unix परंपरा)।

> **⚠ पिछले संस्करणों से संगतता जान-बूझकर तोड़ी गई है।** यह प्रोजेक्ट पहले `voice_in_linux` कहलाता था। नाम बदलने का असर बाइनरी के नाम, सोर्स फ़ाइल के नाम, हर एनवायरनमेंट वेरिएबल (`VOICE_IN_*` → `OPONS_VOXD_*`) और रनटाइम पर `xdotool` की निर्भरता पर पड़ा है (अब उसकी जगह `libxtst-dev` के ज़रिए सीधे XTest से इनपुट बनाया जाता है)। न कोई alias, न कोई संक्रमण अवधि — अपनी लॉन्च स्क्रिप्ट, ऑटोस्टार्ट एंट्री और `apt install` वाली पंक्तियाँ अपडेट कर लें।

## क्यों?

मैं Linux पर किसी भी ऐप्लिकेशन में बोलकर टेक्स्ट लिखवाना चाहता था, वह भी अपनी आवाज़ किसी तीसरे पक्ष के सर्वर पर भेजे बिना। मुझे जितने भी मौजूदा समाधान मिले — ब्राउज़र एक्सटेंशन, क्लाउड API, SaaS प्लेटफ़ॉर्म — सभी ट्रांसक्रिप्शन के लिए आपका ऑडियो दूर के सर्वरों पर स्ट्रीम करते हैं। यानी आपका बोला हर शब्द इंटरनेट से होकर गुज़रता है: ईमेल, गोपनीय दस्तावेज़, क्लाइंट का डेटा, निजी नोट्स — सब कुछ।

यह प्रोजेक्ट एक हल्का और पूरी तरह लोकल विकल्प है। यह पूरी तरह आपकी मशीन पर [whisper.cpp](https://github.com/ggerganov/whisper.cpp) के सहारे चलता है, जो Whisper का लोकल रनटाइम है; Whisper, OpenAI का ओपन-सोर्स स्पीच रिकग्निशन मॉडल है। शुरुआती सेटअप के बाद किसी नेटवर्क कनेक्शन की ज़रूरत नहीं पड़ती। कोई भी डेटा कभी आपके कंप्यूटर से बाहर नहीं जाता।

इसे AI की मदद से बनाया गया है।

## यह कैसे काम करता है

डिक्टेशन के दो तरीक़े, दोनों एक साथ उपलब्ध।

### ट्रे आइकन मोड — एक क्लिक से चालू/बंद, टेक्स्ट क्लिपबोर्ड में

1. आपकी सिस्टम ट्रे में एक छोटा आइकन दिखता है
2. **लेफ़्ट-क्लिक** → रिकॉर्डिंग शुरू (आइकन लाल हो जाता है)
3. **दोबारा लेफ़्ट-क्लिक** → रिकॉर्डिंग रुकती है, Whisper ऑडियो को आपकी मशीन पर ही ट्रांसक्राइब करता है
4. ट्रांसक्राइब हुआ टेक्स्ट अपने-आप आपके क्लिपबोर्ड में कॉपी हो जाता है (X11 के दोनों सिलेक्शन में)
5. एक डेस्कटॉप नोटिफ़िकेशन 10 सेकंड तक टेक्स्ट दिखाता है
6. `Ctrl+Shift+V`, `Shift+Insert` या मिडल-क्लिक से कहीं भी पेस्ट करें

आइकन पर **राइट-क्लिक** करने से एक मेन्यू खुलता है: Toggle / Unload models / Reload models / Quit (देखें [लोकल AI के लिए GPU ख़ाली करना](#लोकल-ai-के-लिए-gpu-ख़ाली-करना-mcp-सर्वर))।

### Push-to-talk मोड — हॉटकी दबाए रखना, कर्सर पर टाइपिंग

1. **`Ctrl+Shift+Space` दबाए रखें** → रिकॉर्डिंग शुरू (आइकन लाल हो जाता है)
2. **कुंजियाँ छोड़ दें** → रिकॉर्डिंग रुकती है, ऑडियो ट्रांसक्राइब होता है
3. ट्रांसक्राइब हुआ टेक्स्ट **सीधे कीबोर्ड कर्सर पर टाइप हो जाता है** (X11 के XTest एक्सटेंशन के ज़रिए), उसी विंडो में जिस पर फ़ोकस है

हॉटकी `OPONS_VOXD_PTT_HOTKEY` से बदली जा सकती है। एक दूसरी, स्वतंत्र हॉटकी (`OPONS_VOXD_PTT_TRANSLATE_HOTKEY`, डिफ़ॉल्ट `ctrl+alt+t`) इसी तरह काम करती है, लेकिन ट्रांसक्रिप्ट की जगह अंग्रेज़ी अनुवाद टाइप करती है — देखें [मुख्य README](../README.md#push-to-talk-and-translate-hotkey)।

## विशेषताएँ

- **100% लोकल** — ऑडियो आपके CPU या GPU पर प्रोसेस होता है, कहीं भेजा नहीं जाता
- **GPU एक्सेलरेशन** — लगभग तुरंत ट्रांसक्रिप्शन के लिए NVIDIA CUDA सपोर्ट
- **99 भाषाएँ** — OpenAI Whisper की बदौलत
- **हल्का** — सादा C, कोई Python नहीं: डेमन, और साथ में एक वैकल्पिक 25 KB का MCP सर्वर, जो सिर्फ़ libc से लिंक होता है
- **सिस्टम ट्रे इंटीग्रेशन** — टास्कबार में एक छोटा आइकन, जो आड़े नहीं आता
- **Push-to-talk हॉटकी** — रिकॉर्ड करने के लिए `Ctrl+Shift+Space` (बदली जा सकती है) दबाए रखें, छोड़ते ही ट्रांसक्रिप्ट कीबोर्ड कर्सर पर टाइप हो जाता है
- **Push-to-talk-और-अनुवाद हॉटकी** — एक दूसरी हॉटकी, जिसे अलग से कॉन्फ़िगर किया जा सकता है और जो शब्दशः ट्रांसक्रिप्ट के बजाय आपकी बात का अंग्रेज़ी अनुवाद टाइप करती है
- **दोहरा क्लिपबोर्ड** — टेक्स्ट X11 के PRIMARY और CLIPBOARD, दोनों सिलेक्शन में जाता है
- **डेस्कटॉप नोटिफ़िकेशन** — ट्रांसक्राइब हुआ टेक्स्ट नोटिफ़िकेशन में दिखता है
- **वॉइस कमांड** — `commands/` में हर भाषा के लिए एक कमांड फ़ाइल, डिफ़ॉल्ट रूप से बंद (`OPONS_VOXD_COMMANDS=1`)। नई भाषा जोड़ने के लिए `commands/xx.txt` बनाएँ, दोबारा कंपाइल करने की ज़रूरत नहीं।
- **अस्थायी नोटिफ़िकेशन** — डिफ़ॉल्ट रूप से नोटिफ़िकेशन दिखते हैं और फिर पूरी तरह ग़ायब हो जाते हैं। `OPONS_VOXD_NOTIFY_PERSIST=1` उन्हें हिस्ट्री में रखता है।
- **नोटिफ़िकेशन मोड** — `OPONS_VOXD_NOTIFY=normal|quiet|silent|off` सफलता वाले नोटिफ़िकेशन तय करता है (डिफ़ॉल्ट `quiet`: बबल, बिना आवाज़)। त्रुटियाँ हमेशा आवाज़ के साथ दिखती हैं, हर मोड में, बिना किसी अपवाद के। पूरी तालिका मुख्य README में है।
- **अपने-आप कैपिटलाइज़ेशन** — वाक्यों का पहला अक्षर अपने-आप कैपिटल हो जाता है
- **ज़रूरत पर GPU ख़ाली करना** — Whisper मॉडल VRAM से अनलोड करें (ट्रे मेन्यू से, या बिल्ट-इन MCP सर्वर के ज़रिए किसी भी AI एजेंट से) और काम पूरा होने पर फिर से लोड करें
- **ऑटो-स्टार्ट** — लॉगिन पर अपने-आप शुरू होने के लिए कॉन्फ़िगर किया जा सकता है

### NVIDIA GPU (वैकल्पिक, लेकिन परफ़ॉर्मेंस के लिए बेहद अहम)

CUDA के बिना, 15 सेकंड की बोली पर **10 से 15 सेकंड** की प्रोसेसिंग मानकर चलें। CUDA के साथ, **1 सेकंड से भी कम**। यानी **10 से 50 गुना** तेज़।

| कंपोनेंट | न्यूनतम | जाँच |
|---|---|---|
| NVIDIA ड्राइवर | 570+ | `nvidia-smi` |
| CUDA Toolkit | 12.0+ | `nvcc --version` |

अगर `nvidia-smi` चलता है लेकिन `nvcc` नहीं, तो CUDA टूलकिट इंस्टॉल करें:

```bash
sudo apt install nvidia-cuda-toolkit
```

अगर `nvidia-smi` में दिखने वाला CUDA वर्ज़न `nvcc` के बताए वर्ज़न से **कम** है, तो ड्राइवर अपडेट करें:

```bash
ubuntu-drivers devices
sudo apt install nvidia-driver-590
sudo reboot
```

## लोकल AI के लिए GPU ख़ाली करना (MCP सर्वर)

Whisper मॉडल हर समय GPU मेमोरी में रहते हैं (`large-v3-turbo` + `medium` के लिए लगभग 3.8 GB)। जब आपको वह VRAM किसी और काम के लिए चाहिए — कोई लोकल LLM, कोई इमेज मॉडल, कोई ट्रेनिंग रन — तो opons-voxd ख़ुद बंद हुए बिना उन्हें अनलोड कर सकता है और बाद में फिर से लोड कर सकता है। अनलोड करने से प्रोसेस का CUDA कॉन्टेक्स्ट भी नष्ट हो जाता है, इसलिए opons-voxd `nvidia-smi` से पूरी तरह ग़ायब हो जाता है (0 MB VRAM)। अगर मॉडल फ़ाइलें अब भी पेज कैश में हैं तो दोबारा लोड होने में एक सेकंड से कम लगता है, वरना कुछ सेकंड।

**ट्रे आइकन की अवस्थाएँ:**

| आइकन | अवस्था |
|:---:|---|
| सफ़ेद छल्ला | मॉडल लोड हैं, तैयार |
| लाल गोला | रिकॉर्डिंग |
| नारंगी गोला | ट्रांसक्रिप्शन जारी |
| तिरछी रेखा से कटा धूसर छल्ला (⊘) | मॉडल अनलोड, GPU मेमोरी ख़ाली, डिक्टेशन बंद |
| नीला तीन-चौथाई चाप | मॉडल फिर से लोड हो रहे हैं |

अनलोड रहते हुए आइकन पर क्लिक करने या push-to-talk हॉटकी दबाने पर रिकॉर्डिंग की जगह एक त्रुटि नोटिफ़िकेशन दिखता है।

**हाथ से:** ट्रे आइकन पर राइट-क्लिक > *Unload models (free GPU memory)* (मॉडल अनलोड करें, GPU मेमोरी ख़ाली करें), फिर *Reload models* (मॉडल फिर से लोड करें)।

**किसी AI एजेंट से (MCP):** डेमन को `-m` / `--mcp` के साथ शुरू करें (डिफ़ॉल्ट रूप से बंद)। `make` साथ में `opons-voxd-mcp` भी बनाता है: stdio पर चलने वाला एक [Model Context Protocol](https://modelcontextprotocol.io) सर्वर, जो सिर्फ़ libc से लिंक होता है (लगभग 1.5 MB RAM)। यह तीन टूल देता है: `unload_models`, `reload_models` और `get_status`। Claude Code के साथ:

```bash
claude mcp add --scope user opons-voxd -- /path/to/opons-voxd/opons-voxd-mcp
```

ज़्यादातर दूसरे क्लाइंट (Claude Desktop, Cursor, LM Studio...) यह JSON इस्तेमाल करते हैं:

```json
{ "mcpServers": { "opons-voxd": { "command": "/path/to/opons-voxd/opons-voxd-mcp" } } }
```

## Push-to-talk हॉटकी

साथ आने वाली `launch.sh` फ़ाइल `ctrl+alt+w` (AZERTY पर सुझाई गई) या `ctrl+alt+z` (QWERTY पर सुझाई गई) इस्तेमाल करती है। यह कुंजी `A` के ठीक बगल में है, इसलिए पूरा कॉम्बिनेशन सिर्फ़ बाएँ हाथ से दब जाता है (छोटी उँगली `Ctrl` पर, अँगूठा `Alt` पर, अनामिका या बीच की उँगली `W`/`Z` पर)। टाइपिंग की मुद्रा नहीं बिगड़ती, और ज़्यादातर डेस्कटॉप एनवायरनमेंट में यह कॉम्बिनेशन डिफ़ॉल्ट रूप से किसी और काम के लिए तय नहीं होता। इसे `OPONS_VOXD_PTT_HOTKEY` से कॉन्फ़िगर करें। पूरा विवरण [मुख्य README](../README.md#push-to-talk-hotkey) में।
