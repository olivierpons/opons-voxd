# opons-voxd

> ملاحظة: لا علاقة لـ opons-voxd بمشروع jakovius/voxd. اختير الاسم باستقلال تام — `opons` = O. Pons (المؤلف)، و`voxd` = vox + daemon (على تقليد اللاتينية وUnix).

> **⚠ التوافق مع الإصدارات السابقة مكسور عمدًا.** كان اسم هذا المشروع سابقًا `voice_in_linux`. شمل تغيير الاسم اسمَ الملف التنفيذي، واسمَ الملف المصدري، وكلَّ متغيرات البيئة (`VOICE_IN_*` → `OPONS_VOXD_*`)، والاعتمادَ وقت التشغيل على `xdotool` (حلّ محله توليد مباشر لضغطات المفاتيح عبر XTest بواسطة `libxtst-dev`). لا أسماء بديلة ولا فترة انتقالية — حدِّث سكربتات التشغيل، ومدخلات التشغيل التلقائي، وأسطر `apt install`.

**إملاء صوتي محلي يحوّل الكلام إلى نص على Linux — صوتك لا يغادر جهازك أبدًا.**

## لماذا؟

أردتُ أن أُملي نصوصًا في أي تطبيق على Linux دون أن أرسل صوتي إلى خادم تابع لطرف ثالث. كل الحلول التي وجدتها — إضافات المتصفح، وواجهات API السحابية، ومنصات SaaS — ترسل صوتك إلى خوادم بعيدة لتفريغه نصيًا. أي إن كل كلمة تنطقها تعبر الإنترنت: الرسائل الإلكترونية، والمستندات السرية، وبيانات العملاء، والملاحظات الشخصية — كلها.

هذا المشروع بديل خفيف ومحلي بالكامل. يعمل كليًا على جهازك باستخدام [whisper.cpp](https://github.com/ggerganov/whisper.cpp)، وهو بيئة تشغيل محلية لـ Whisper، نموذج التعرف على الكلام مفتوح المصدر من OpenAI. لا حاجة إلى اتصال بالشبكة بعد الإعداد الأولي، ولا تغادر أي بيانات حاسوبك أبدًا.

بُني بمساعدة الذكاء الاصطناعي.

## آلية العمل

طريقتان للإملاء، متاحتان في الوقت نفسه.

### وضع أيقونة شريط النظام — نقرة للتشغيل والإيقاف، ونسخ إلى الحافظة

1. تظهر أيقونة صغيرة في شريط النظام
2. **نقرة يسرى** ← يبدأ التسجيل (تتحول الأيقونة إلى الأحمر)
3. **نقرة يسرى ثانية** ← يتوقف التسجيل، ويُفرَّغ الصوت محليًا عبر Whisper
4. يُنسخ النص المفرَّغ تلقائيًا إلى الحافظة (في كلا تحديدَي X11)
5. يعرض إشعار على سطح المكتب النص لمدة 10 ثوانٍ
6. الصق في أي مكان بـ `Ctrl+Shift+V` أو `Shift+Insert` أو بالنقر بزر الفأرة الأوسط

**انقر بزر الفأرة الأيمن** على الأيقونة لفتح قائمة فيها Toggle / Unload models / Reload models / Quit (راجع [تحرير GPU للذكاء الاصطناعي المحلي](#تحرير-gpu-للذكاء-الاصطناعي-المحلي-خادم-mcp)).

### وضع الضغط للتحدث (push-to-talk) — ضغط مطوّل على اختصار، وكتابة عند المؤشر

1. **اضغط مطولًا على `Ctrl+Shift+Space`** ← يبدأ التسجيل (تتحول الأيقونة إلى الأحمر)
2. **أفلت المفاتيح** ← يتوقف التسجيل ويُفرَّغ الصوت
3. النص المفرَّغ **يُكتب مباشرة عند مؤشر لوحة المفاتيح** (عبر امتداد XTest في X11) في النافذة التي عليها التركيز

يمكن ضبط الاختصار عبر `OPONS_VOXD_PTT_HOTKEY`. وثمة اختصار ثانٍ مستقل (`OPONS_VOXD_PTT_TRANSLATE_HOTKEY`، افتراضيًا `ctrl+alt+t`) يعمل بالطريقة نفسها لكنه يكتب ترجمة إنجليزية بدلًا من النص الأصلي — راجع [الـ README الرئيسي](../README.md#push-to-talk-and-translate-hotkey).

## الميزات

- **محلي بنسبة 100%** — يُعالَج الصوت على المعالج (CPU) أو GPU، ولا يُرسَل إلى أي مكان
- **تسريع عبر GPU** — دعم NVIDIA CUDA لتفريغ شبه فوري
- **99 لغة** — بفضل OpenAI Whisper
- **خفيف** — لغة C خالصة، بلا Python: الخدمة الخلفية (daemon)، ومعها خادم MCP اختياري بحجم 25 كيلوبايت مربوط بمكتبة libc وحدها
- **تكامل مع شريط النظام** — أيقونة غير مزعجة في شريط المهام
- **اختصار الضغط للتحدث** — اضغط مطولًا على `Ctrl+Shift+Space` (قابل للتخصيص) للتسجيل، وأفلت ليُكتب النص المفرَّغ عند مؤشر لوحة المفاتيح
- **اختصار الضغط للتحدث مع الترجمة** — اختصار ثانٍ يُخصَّص باستقلال، يكتب ترجمة إنجليزية لكلامك بدلًا من التفريغ الحرفي
- **حافظة مزدوجة** — يُرسَل النص إلى تحديدَي X11 كليهما: PRIMARY وCLIPBOARD
- **إشعارات سطح المكتب** — يُعرض النص المفرَّغ في إشعار
- **أوامر صوتية** — ملف أوامر واحد لكل لغة في `commands/`، وهي معطَّلة افتراضيًا (`OPONS_VOXD_COMMANDS=1`). لإضافة لغة يكفي إنشاء `commands/xx.txt`، دون حاجة إلى إعادة البناء.
- **إشعارات عابرة** — افتراضيًا تظهر الإشعارات ثم تختفي تمامًا. ويُبقيها المتغير `OPONS_VOXD_NOTIFY_PERSIST=1` في السجل.
- **وضع الإشعارات** — يتحكم المتغير `OPONS_VOXD_NOTIFY=normal|quiet|silent|off` في إشعارات النجاح (الافتراضي `quiet`: فقاعة بلا صوت). أما الأخطاء فتظهر دائمًا مع صوت، في كل الأوضاع، دون استثناء. راجع الـ README الرئيسي للاطلاع على الجدول الكامل.
- **حرف كبير تلقائي** — تبدأ الجمل بحرف كبير تلقائيًا
- **تحرير GPU عند الطلب** — ألغِ تحميل نماذج Whisper من VRAM (من قائمة شريط النظام، أو عبر أي وكيل ذكاء اصطناعي من خلال خادم MCP المدمج) ثم أعد تحميلها عند الانتهاء
- **تشغيل تلقائي** — يمكن ضبطه ليبدأ عند تسجيل الدخول

### بطاقة رسوميات NVIDIA (اختيارية لكنها حاسمة للأداء)

بدون CUDA، توقّع **من 10 إلى 15 ثانية** من المعالجة لكل 15 ثانية من الكلام. ومع CUDA، **أقل من ثانية واحدة**. أي تسريع يتراوح بين **10 و50 ضعفًا**.

| المكوّن | الحد الأدنى | التحقق |
|---|---|---|
| تعريف NVIDIA | 570+ | `nvidia-smi` |
| CUDA Toolkit | 12.0+ | `nvcc --version` |

إذا كان `nvidia-smi` يعمل بينما لا يعمل `nvcc`، فثبّت حزمة أدوات CUDA:

```bash
sudo apt install nvidia-cuda-toolkit
```

إذا كان إصدار CUDA الذي يعرضه `nvidia-smi` **أدنى** من الإصدار الذي يعرضه `nvcc`، فحدِّث التعريف:

```bash
ubuntu-drivers devices
sudo apt install nvidia-driver-590
sudo reboot
```

## التثبيت

```bash
# 1. اعتماديات النظام
sudo apt update
sudo apt install -y \
    build-essential cmake pkg-config git curl \
    libgtk-3-dev libnotify-dev libportaudio2 libcairo2-dev libx11-dev libxtst-dev \
    xclip libnotify-bin

# 2. استنساخ المستودع
git clone https://github.com/olivierpons/opons-voxd.git
cd opons-voxd

# 3. بناء whisper.cpp وتنزيل النموذج
make setup

# 4. بناء الملفات التنفيذية: opons-voxd (الخدمة الخلفية) وopons-voxd-mcp (خادم MCP اختياري)
make

# 5. التشغيل
./opons-voxd
```

## تحرير GPU للذكاء الاصطناعي المحلي (خادم MCP)

تبقى نماذج Whisper في ذاكرة GPU طوال الوقت (نحو 3.8 غيغابايت لـ `large-v3-turbo` + `medium`). وحين تحتاج تلك الذاكرة (VRAM) لشيء آخر — نموذج لغوي كبير (LLM) محلي، أو نموذج للصور، أو عملية تدريب — يستطيع opons-voxd إلغاء تحميلها ثم إعادة تحميلها لاحقًا دون الخروج من البرنامج. كما يُتلف إلغاءُ التحميل سياقَ CUDA الخاص بالعملية، فيختفي opons-voxd تمامًا من `nvidia-smi` (0 ميغابايت من VRAM). تستغرق إعادة التحميل أقل من ثانية إن كانت ملفات النماذج لا تزال في ذاكرة التخزين المؤقت للصفحات (page cache)، وبضع ثوانٍ في غير ذلك.

**حالات أيقونة شريط النظام:**

| الأيقونة | الحالة |
|:---:|---|
| حلقة بيضاء | النماذج محمَّلة، جاهز |
| قرص أحمر | تسجيل |
| قرص برتقالي | تفريغ نصي |
| حلقة رمادية مشطوبة (⊘) | النماذج غير محمَّلة، ذاكرة GPU محرَّرة، الإملاء معطَّل |
| قوس أزرق بثلاثة أرباع دائرة | إعادة تحميل النماذج |

ما دامت النماذج غير محمَّلة، يؤدي النقر على الأيقونة أو الضغط على أحد اختصارات الضغط للتحدث إلى إظهار إشعار خطأ بدلًا من بدء التسجيل.

**يدويًا:** انقر بزر الفأرة الأيمن على أيقونة شريط النظام > *Unload models (free GPU memory)* (إلغاء تحميل النماذج وتحرير ذاكرة GPU)، ثم *Reload models* (إعادة تحميل النماذج).

**من وكيل ذكاء اصطناعي (MCP):** شغّل الخدمة الخلفية مع `-m` / `--mcp` (معطَّل افتراضيًا). يبني `make` أيضًا `opons-voxd-mcp`، وهو خادم [Model Context Protocol](https://modelcontextprotocol.io) يعمل عبر stdio، مربوط بمكتبة libc وحدها (نحو 1.5 ميغابايت من الذاكرة RAM). يوفّر ثلاث أدوات: `unload_models` و`reload_models` و`get_status`. مع Claude Code:

```bash
claude mcp add --scope user opons-voxd -- /path/to/opons-voxd/opons-voxd-mcp
```

تستخدم معظم برامج العميل الأخرى (Claude Desktop وCursor وLM Studio...) صيغة JSON هذه:

```json
{ "mcpServers": { "opons-voxd": { "command": "/path/to/opons-voxd/opons-voxd-mcp" } } }
```

التفاصيل الكاملة في [الـ README الرئيسي](../README.md#free-the-gpu-for-local-ai-mcp-server).

## اختصار الضغط للتحدث

يستخدم الملف `launch.sh` المرفق الاختصار `ctrl+alt+w` (يُنصح به على لوحات AZERTY) أو `ctrl+alt+z` (يُنصح به على لوحات QWERTY). يقع هذا المفتاح بجوار `A`، فيمكن بلوغ التركيبة كاملة باليد اليسرى وحدها (الخنصر على `Ctrl`، والإبهام على `Alt`، والبنصر أو الوسطى على `W`/`Z`) دون الإخلال بوضعية الكتابة، كما أنها غير مستخدمة افتراضيًا في معظم بيئات سطح المكتب. اضبطه عبر `OPONS_VOXD_PTT_HOTKEY`. التفاصيل الكاملة في [الـ README الرئيسي](../README.md#push-to-talk-hotkey).
