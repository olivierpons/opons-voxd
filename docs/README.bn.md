# opons-voxd

> দ্রষ্টব্য: jakovius/voxd-এর সঙ্গে opons-voxd-এর কোনো সম্পর্ক নেই। নামটি স্বাধীনভাবে বেছে নেওয়া — `opons` = O. Pons (লেখক), `voxd` = vox + daemon (লাতিন/Unix ঐতিহ্য)।

> **⚠ পুরোনো সংস্করণের সঙ্গে সামঞ্জস্য ইচ্ছে করেই ভাঙা হয়েছে।** এই প্রকল্পের আগের নাম ছিল `voice_in_linux`। নাম বদলের ফলে বদলে গেছে বাইনারির নাম, সোর্স ফাইলের নাম আর প্রতিটি এনভায়রনমেন্ট ভেরিয়েবল (`VOICE_IN_*` → `OPONS_VOXD_*`); রানটাইমে `xdotool`-এর ওপর নির্ভরতাও আর নেই (তার জায়গায় এখন `libxtst-dev`-এর মাধ্যমে সরাসরি XTest দিয়ে ইনপুট তৈরি হয়)। কোনো alias নেই, কোনো অন্তর্বর্তী সময়ও নেই — আপনার লঞ্চ স্ক্রিপ্ট, অটোস্টার্ট এন্ট্রি আর `apt install`-এর লাইনগুলো হালনাগাদ করে নিন।

**Linux-এর জন্য লোকাল স্পিচ-টু-টেক্সট ডিকটেশন — আপনার কণ্ঠস্বর কখনো আপনার মেশিনের বাইরে যায় না।**

## কেন?

আমি চেয়েছিলাম Linux-এ যেকোনো অ্যাপ্লিকেশনে মুখে বলে লিখতে, কিন্তু নিজের কণ্ঠস্বর কোনো তৃতীয় পক্ষের সার্ভারে না পাঠিয়ে। যত সমাধান খুঁজে পেয়েছি — ব্রাউজার এক্সটেনশন, ক্লাউড API, SaaS প্ল্যাটফর্ম — সবগুলোই ট্রান্সক্রিপশনের জন্য আপনার অডিও দূরের সার্ভারে স্ট্রিম করে। অর্থাৎ আপনার বলা প্রতিটি শব্দ ইন্টারনেট দিয়ে যায়: ইমেল, গোপন নথি, ক্লায়েন্টের ডেটা, ব্যক্তিগত নোট — সবকিছু।

এই প্রকল্পটি একটি হালকা, পুরোপুরি লোকাল বিকল্প। এটি সম্পূর্ণভাবে আপনার মেশিনেই চলে, [whisper.cpp](https://github.com/ggerganov/whisper.cpp) ব্যবহার করে; whisper.cpp হলো Whisper-এর একটি লোকাল রানটাইম, আর Whisper হলো OpenAI-এর ওপেন-সোর্স স্পিচ রিকগনিশন মডেল। প্রাথমিক সেটআপের পর আর কোনো নেটওয়ার্ক সংযোগের দরকার হয় না। কোনো ডেটা কখনো আপনার কম্পিউটারের বাইরে যায় না।

AI-এর সাহায্যে তৈরি।

## কীভাবে কাজ করে

ডিকটেশনের দুটি উপায়, দুটোই একসঙ্গে পাওয়া যায়।

### ট্রে আইকন মোড — এক ক্লিকে চালু/বন্ধ, টেক্সট ক্লিপবোর্ডে

1. আপনার সিস্টেম ট্রেতে একটি ছোট আইকন দেখা যায়
2. **বাঁ-ক্লিক** → রেকর্ডিং শুরু (আইকন লাল হয়ে যায়)
3. **আবার বাঁ-ক্লিক** → রেকর্ডিং থামে, Whisper আপনার মেশিনেই অডিওটি ট্রান্সক্রাইব করে
4. ট্রান্সক্রাইব করা টেক্সট আপনা থেকেই আপনার ক্লিপবোর্ডে কপি হয়ে যায় (X11-এর দুটো সিলেকশনেই)
5. একটি ডেস্কটপ নোটিফিকেশন টেক্সটটি 10 সেকেন্ড ধরে দেখায়
6. `Ctrl+Shift+V`, `Shift+Insert` বা মিডল-ক্লিক দিয়ে যেকোনো জায়গায় পেস্ট করুন

আইকনে **ডান-ক্লিক** করলে একটি মেনু খোলে: Toggle / Unload models / Reload models / Quit (দেখুন [লোকাল AI-এর জন্য GPU খালি করা](#লোকাল-ai-এর-জন্য-gpu-খালি-করা-mcp-সার্ভার))।

### Push-to-talk মোড — হটকি চেপে ধরা, কার্সারে টাইপ

1. **`Ctrl+Shift+Space` চেপে ধরুন** → রেকর্ডিং শুরু (আইকন লাল হয়ে যায়)
2. **কি-গুলো ছেড়ে দিন** → রেকর্ডিং থামে, অডিও ট্রান্সক্রাইব হয়
3. ট্রান্সক্রাইব করা টেক্সট **সরাসরি কিবোর্ড কার্সারে টাইপ হয়ে যায়** (X11-এর XTest এক্সটেনশনের মাধ্যমে), যে উইন্ডোতে ফোকাস আছে সেখানেই

হটকিটি `OPONS_VOXD_PTT_HOTKEY` দিয়ে বদলানো যায়। দ্বিতীয় একটি স্বতন্ত্র হটকি (`OPONS_VOXD_PTT_TRANSLATE_HOTKEY`, ডিফল্ট `ctrl+alt+t`) একইভাবে কাজ করে, তবে ট্রান্সক্রিপ্টের বদলে ইংরেজি অনুবাদ টাইপ করে — দেখুন [মূল README](../README.md#push-to-talk-and-translate-hotkey)।

## বৈশিষ্ট্য

- **100% লোকাল** — অডিও প্রসেস হয় আপনার CPU বা GPU-তে, কোথাও পাঠানো হয় না
- **GPU অ্যাক্সেলারেশন** — প্রায় তাৎক্ষণিক ট্রান্সক্রিপশনের জন্য NVIDIA CUDA সমর্থন
- **99টি ভাষা** — OpenAI Whisper-এর সৌজন্যে
- **হালকা** — সাধারণ C, কোনো Python নেই: ডেমন, আর সঙ্গে একটি ঐচ্ছিক 25 KB MCP সার্ভার, যা শুধু libc-এর সঙ্গে লিংক করা
- **সিস্টেম ট্রে ইন্টিগ্রেশন** — টাস্কবারে ছোট্ট একটি আইকন, যা কাজে বাধা দেয় না
- **Push-to-talk হটকি** — রেকর্ড করতে `Ctrl+Shift+Space` (বদলানো যায়) চেপে ধরুন, ছাড়লেই ট্রান্সক্রিপ্ট কিবোর্ড কার্সারে টাইপ হয়ে যায়
- **Push-to-talk-ও-অনুবাদ হটকি** — দ্বিতীয় একটি হটকি, যা আলাদাভাবে কনফিগার করা যায় এবং হুবহু ট্রান্সক্রিপ্টের বদলে আপনার কথার ইংরেজি অনুবাদ টাইপ করে
- **দ্বৈত ক্লিপবোর্ড** — টেক্সট X11-এর PRIMARY আর CLIPBOARD, দুটো সিলেকশনেই যায়
- **ডেস্কটপ নোটিফিকেশন** — ট্রান্সক্রাইব করা টেক্সট নোটিফিকেশনে দেখা যায়
- **ভয়েস কমান্ড** — `commands/`-এ প্রতিটি ভাষার জন্য একটি কমান্ড ফাইল, ডিফল্টভাবে বন্ধ (`OPONS_VOXD_COMMANDS=1`)। নতুন ভাষা যোগ করতে `commands/xx.txt` তৈরি করুন, আবার কম্পাইল করার দরকার নেই।
- **ক্ষণস্থায়ী নোটিফিকেশন** — ডিফল্টভাবে নোটিফিকেশন দেখা দিয়ে তারপর পুরোপুরি মিলিয়ে যায়। `OPONS_VOXD_NOTIFY_PERSIST=1` সেগুলোকে হিস্টরিতে রেখে দেয়।
- **নোটিফিকেশন মোড** — `OPONS_VOXD_NOTIFY=normal|quiet|silent|off` সফল হলে যে নোটিফিকেশন আসে তা নিয়ন্ত্রণ করে (ডিফল্ট `quiet`: বাবল, শব্দ নেই)। ত্রুটি সবসময় শব্দসহ দেখায়, প্রতিটি মোডে, কোনো ব্যতিক্রম ছাড়াই। পুরো টেবিলটি মূল README-তে আছে।
- **স্বয়ংক্রিয় ক্যাপিটালাইজেশন** — বাক্যের প্রথম অক্ষর আপনা থেকেই ক্যাপিটাল হয়
- **প্রয়োজনমতো GPU খালি করা** — Whisper মডেলগুলো VRAM থেকে আনলোড করুন (ট্রে মেনু থেকে, বা বিল্ট-ইন MCP সার্ভারের মাধ্যমে যেকোনো AI এজেন্ট থেকে), কাজ শেষ হলে আবার লোড করুন
- **অটো-স্টার্ট** — লগইনের সময় নিজে থেকে চালু হওয়ার জন্য কনফিগার করা যায়

### NVIDIA GPU (ঐচ্ছিক, তবে পারফরম্যান্সের জন্য অপরিহার্য)

CUDA ছাড়া, 15 সেকেন্ডের কথার জন্য **10 থেকে 15 সেকেন্ড** প্রসেসিং ধরে রাখুন। CUDA থাকলে **1 সেকেন্ডেরও কম**। অর্থাৎ **10 থেকে 50 গুণ** দ্রুত।

| উপাদান | ন্যূনতম | যাচাই |
|---|---|---|
| NVIDIA ড্রাইভার | 570+ | `nvidia-smi` |
| CUDA Toolkit | 12.0+ | `nvcc --version` |

যদি `nvidia-smi` কাজ করে কিন্তু `nvcc` না করে, তাহলে CUDA টুলকিট ইনস্টল করুন:

```bash
sudo apt install nvidia-cuda-toolkit
```

`nvidia-smi`-তে দেখানো CUDA সংস্করণ যদি `nvcc`-র জানানো সংস্করণের চেয়ে **কম** হয়, তাহলে ড্রাইভার হালনাগাদ করুন:

```bash
ubuntu-drivers devices
sudo apt install nvidia-driver-590
sudo reboot
```

## ইনস্টলেশন

```bash
# 1. সিস্টেম ডিপেনডেন্সি
sudo apt update
sudo apt install -y \
    build-essential cmake pkg-config git curl \
    libgtk-3-dev libnotify-dev libportaudio2 libcairo2-dev libx11-dev libxtst-dev \
    xclip libnotify-bin

# 2. রিপোজিটরি ক্লোন করুন
git clone https://github.com/olivierpons/opons-voxd.git
cd opons-voxd

# 3. whisper.cpp বিল্ড করুন এবং মডেল ডাউনলোড করুন
```

## লোকাল AI-এর জন্য GPU খালি করা (MCP সার্ভার)

Whisper মডেলগুলো সারাক্ষণ GPU মেমোরিতে থাকে (`large-v3-turbo` + `medium` মিলিয়ে প্রায় 3.8 GB)। সেই VRAM অন্য কোনো কাজে দরকার হলে — লোকাল LLM, ইমেজ মডেল, ট্রেনিং রান — opons-voxd নিজে বন্ধ না হয়েই মডেলগুলো আনলোড করতে পারে, পরে আবার লোডও করতে পারে। আনলোড করলে প্রসেসের CUDA কনটেক্সটও মুছে যায়, ফলে opons-voxd `nvidia-smi` থেকে পুরোপুরি উধাও হয়ে যায় (0 MB VRAM)। মডেল ফাইলগুলো তখনো পেজ ক্যাশে থাকলে আবার লোড হতে এক সেকেন্ডেরও কম লাগে, নইলে কয়েক সেকেন্ড।

**ট্রে আইকনের অবস্থা:**

| আইকন | অবস্থা |
|:---:|---|
| সাদা বলয় | মডেল লোড করা, প্রস্তুত |
| লাল ভরাট বৃত্ত | রেকর্ডিং |
| কমলা ভরাট বৃত্ত | ট্রান্সক্রিপশন চলছে |
| আড়াআড়ি দাগ কাটা ধূসর বলয় (⊘) | মডেল আনলোড, GPU মেমোরি খালি, ডিকটেশন বন্ধ |
| নীল তিন-চতুর্থাংশ বৃত্তচাপ | মডেল আবার লোড হচ্ছে |

মডেল আনলোড থাকা অবস্থায় আইকনে ক্লিক করলে বা push-to-talk হটকি চাপলে রেকর্ডিংয়ের বদলে একটি ত্রুটির নোটিফিকেশন দেখায়।

**হাতে:** ট্রে আইকনে ডান-ক্লিক > *Unload models (free GPU memory)* (মডেল আনলোড করে GPU মেমোরি খালি করা), তারপর *Reload models* (মডেল আবার লোড করা)।

**AI এজেন্ট থেকে (MCP):** ডেমনটি `-m` / `--mcp` দিয়ে চালু করুন (ডিফল্টভাবে বন্ধ)। `make` সঙ্গে `opons-voxd-mcp`-ও তৈরি করে: stdio-র ওপর চলা একটি [Model Context Protocol](https://modelcontextprotocol.io) সার্ভার, যা শুধু libc-এর সঙ্গে লিংক করা (প্রায় 1.5 MB RAM)। এটি তিনটি টুল দেয়: `unload_models`, `reload_models` এবং `get_status`। Claude Code-এর সঙ্গে:

```bash
claude mcp add --scope user opons-voxd -- /path/to/opons-voxd/opons-voxd-mcp
```

অন্য বেশিরভাগ ক্লায়েন্ট (Claude Desktop, Cursor, LM Studio...) এই JSON ব্যবহার করে:

```json
{ "mcpServers": { "opons-voxd": { "command": "/path/to/opons-voxd/opons-voxd-mcp" } } }
```

পুরো বিবরণ [মূল README](../README.md#free-the-gpu-for-local-ai-mcp-server)-তে।

## Push-to-talk হটকি

সঙ্গে দেওয়া `launch.sh` ব্যবহার করে `ctrl+alt+w` (AZERTY-তে প্রস্তাবিত) বা `ctrl+alt+z` (QWERTY-তে প্রস্তাবিত)। কি-টি `A`-র ঠিক পাশে, তাই পুরো কম্বিনেশনটি শুধু বাঁ হাতেই চাপা যায় (কড়ে আঙুল `Ctrl`-এ, বুড়ো আঙুল `Alt`-এ, অনামিকা বা মধ্যমা `W`/`Z`-এ)। টাইপ করার ভঙ্গি ভাঙতে হয় না, আর বেশিরভাগ ডেস্কটপ এনভায়রনমেন্টে এই কম্বিনেশন ডিফল্টভাবে অন্য কোনো কাজে বাঁধা থাকে না। `OPONS_VOXD_PTT_HOTKEY` দিয়ে এটি কনফিগার করুন। পুরো বিবরণ [মূল README](../README.md#push-to-talk-hotkey)-তে।
