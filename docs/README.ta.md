# opons-voxd

> குறிப்பு: opons-voxd-க்கும் jakovius/voxd-க்கும் எந்தத் தொடர்பும் இல்லை. இந்தப் பெயர் தனித்தே தேர்ந்தெடுக்கப்பட்டது — `opons` = O. Pons (ஆசிரியர்), `voxd` = vox + daemon (லத்தீன்/Unix மரபு).

> **⚠ பழைய பதிப்புகளுடனான இணக்கம் வேண்டுமென்றே கைவிடப்பட்டுள்ளது.** இந்தத் திட்டத்தின் முந்தைய பெயர் `voice_in_linux`. பெயர் மாற்றம் பைனரியின் பெயர், மூலக் கோப்பின் பெயர், ஒவ்வொரு சூழல் மாறியும் (`VOICE_IN_*` → `OPONS_VOXD_*`), இயக்க நேரத்தில் `xdotool` மீதிருந்த சார்பு (இப்போது அதற்குப் பதிலாக `libxtst-dev` வழியாக XTest மூலம் விசை நிகழ்வுகள் நேரடியாக உருவாக்கப்படுகின்றன) ஆகிய அனைத்தையும் பாதித்தது. மாற்றுப் பெயர்கள் இல்லை, படிப்படியான விலக்கல் காலமும் இல்லை — உங்கள் தொடக்க ஸ்கிரிப்டுகள், தானியங்கித் தொடக்க உள்ளீடுகள், `apt install` வரிகள் ஆகியவற்றைப் புதுப்பிக்கவும்.

**Linux-க்கான உள்ளூர் பேச்சு-உரை டிக்டேஷன் — உங்கள் குரல் உங்கள் கணினியை விட்டு ஒருபோதும் வெளியேறாது.**

## ஏன்?

என் குரலை மூன்றாம் தரப்பு சர்வருக்கு அனுப்பாமல், Linux-இல் எந்தப் பயன்பாட்டிலும் டிக்டேஷன் மூலம் உரை உள்ளிட விரும்பினேன். நான் கண்ட ஒவ்வொரு தீர்வும் — உலாவி நீட்டிப்புகள், கிளவுட் API-கள், SaaS தளங்கள் — படியெடுப்பதற்காக உங்கள் ஒலியைத் தொலை சர்வர்களுக்கு அனுப்புகிறது. அதாவது நீங்கள் பேசும் ஒவ்வொரு சொல்லும் இணையம் வழியாகப் பயணிக்கிறது: மின்னஞ்சல்கள், ரகசிய ஆவணங்கள், வாடிக்கையாளர் தரவு, தனிப்பட்ட குறிப்புகள் — எல்லாமே.

இந்தத் திட்டம் இலகுவான, முழுமையாக உள்ளூரில் இயங்கும் மாற்று. இது [whisper.cpp](https://github.com/ggerganov/whisper.cpp)-ஐப் பயன்படுத்தி முழுவதுமாக உங்கள் கணினியிலேயே இயங்குகிறது; whisper.cpp என்பது OpenAI-இன் திறந்த மூலப் பேச்சு அறிதல் மாடலான Whisper-ஐ உள்ளூரில் இயக்கும் இயக்கச் சூழல். ஆரம்ப அமைப்புக்குப் பிறகு பிணைய இணைப்பு தேவையில்லை. எந்தத் தரவும் உங்கள் கணினியை விட்டு வெளியேறுவதில்லை.

AI-இன் உதவியுடன் உருவாக்கப்பட்டது.

## செயல்படும் விதம்

டிக்டேஷன் செய்ய இரண்டு வழிகள், இரண்டும் ஒரே நேரத்தில் கிடைக்கும்.

### ட்ரே ஐகான் பயன்முறை — கிளிக்கில் தொடக்கம்/நிறுத்தம், கிளிப்போர்டுக்கு நகல்

1. உங்கள் சிஸ்டம் ட்ரேயில் ஒரு சிறிய ஐகான் தோன்றும்
2. **இடது கிளிக்** → பதிவு தொடங்குகிறது (ஐகான் சிவப்பாக மாறும்)
3. **மீண்டும் இடது கிளிக்** → பதிவு நிற்கிறது, ஒலி Whisper மூலம் உள்ளூரிலேயே படியெடுக்கப்படுகிறது
4. படியெடுத்த உரை தானாகவே உங்கள் கிளிப்போர்டுக்கு நகலெடுக்கப்படும் (X11-இன் இரண்டு தேர்வுகளிலும்)
5. டெஸ்க்டாப் அறிவிப்பு ஒன்று உரையை 10 வினாடிகள் காட்டும்
6. `Ctrl+Shift+V`, `Shift+Insert` அல்லது நடு கிளிக் மூலம் எங்கு வேண்டுமானாலும் ஒட்டலாம்

ஐகானில் **வலது கிளிக்** செய்தால் Toggle / Unload models / Reload models / Quit கொண்ட மெனு திறக்கும் ([உள்ளூர் AI-க்காக GPU-ஐ விடுவித்தல்](#உள்ளூர்-ai-க்காக-gpu-ஐ-விடுவித்தல்-mcp-சர்வர்) பார்க்கவும்).

### Push-to-talk பயன்முறை — ஹாட்கீயை அழுத்திப் பிடித்தல், கர்சரில் தட்டச்சு

1. **`Ctrl+Shift+Space`-ஐ அழுத்திப் பிடிக்கவும்** → பதிவு தொடங்குகிறது (ஐகான் சிவப்பாக மாறும்)
2. **விசைகளை விடுங்கள்** → பதிவு நிற்கிறது, ஒலி படியெடுக்கப்படுகிறது
3. படியெடுத்த உரை, ஃபோகஸில் உள்ள சாளரத்தில் **நேரடியாக விசைப்பலகை கர்சரில் தட்டச்சு ஆகும்** (X11 XTest நீட்டிப்பு வழியாக)

ஹாட்கீயை `OPONS_VOXD_PTT_HOTKEY` மூலம் மாற்றலாம். இரண்டாவது, தனித்த ஹாட்கீ (`OPONS_VOXD_PTT_TRANSLATE_HOTKEY`, இயல்புநிலை `ctrl+alt+t`) அதே வழியில் இயங்கும், ஆனால் அதற்குப் பதிலாக ஆங்கில மொழிபெயர்ப்பைத் தட்டச்சு செய்யும் — [முதன்மை README](../README.md#push-to-talk-and-translate-hotkey)-ஐப் பார்க்கவும்.

## அம்சங்கள்

- **100% உள்ளூர்** — ஒலி உங்கள் CPU அல்லது GPU-வில் செயலாக்கப்படுகிறது, எங்கும் அனுப்பப்படுவதில்லை
- **GPU முடுக்கம்** — கிட்டத்தட்ட உடனடிப் படியெடுப்புக்கு NVIDIA CUDA ஆதரவு
- **99 மொழிகள்** — OpenAI Whisper மூலம்
- **இலகுவானது** — தூய C, Python இல்லை: daemon, கூடவே libc-உடன் மட்டுமே இணைக்கப்பட்ட, விருப்பத்தேர்வான 25 KB MCP சர்வர்
- **சிஸ்டம் ட்ரே ஒருங்கிணைப்பு** — பணிப்பட்டியில் தொந்தரவு தராத ஐகான்
- **Push-to-talk ஹாட்கீ** — பதிவு செய்ய `Ctrl+Shift+Space`-ஐ (மாற்றக்கூடியது) அழுத்திப் பிடிக்கவும்; விட்டதும் படியெடுத்த உரை விசைப்பலகை கர்சரில் தட்டச்சு ஆகும்
- **Push-to-talk-மற்றும்-மொழிபெயர்ப்பு ஹாட்கீ** — தனியாக அமைக்கக்கூடிய இரண்டாவது ஹாட்கீ, சொல்லுக்குச் சொல் படியெடுப்புக்குப் பதிலாக உங்கள் பேச்சின் ஆங்கில மொழிபெயர்ப்பைத் தட்டச்சு செய்யும்
- **இரட்டை கிளிப்போர்டு** — உரை X11-இன் PRIMARY, CLIPBOARD ஆகிய இரண்டு தேர்வுகளுக்கும் அனுப்பப்படுகிறது
- **டெஸ்க்டாப் அறிவிப்புகள்** — படியெடுத்த உரை அறிவிப்பாகக் காட்டப்படும்
- **குரல் கட்டளைகள்** — ஒவ்வொரு மொழிக்கும் `commands/`-இல் ஒரு கட்டளைக் கோப்பு, இயல்பாக முடக்கப்பட்டுள்ளன (`OPONS_VOXD_COMMANDS=1`). `commands/xx.txt` கோப்பை உருவாக்கி ஒரு மொழியைச் சேர்க்கலாம்; மீண்டும் தொகுக்க (recompile) வேண்டியதில்லை.
- **தற்காலிக அறிவிப்புகள்** — இயல்பாக, அறிவிப்புகள் தோன்றிப் பின்னர் முழுவதுமாக மறைந்துவிடும். `OPONS_VOXD_NOTIFY_PERSIST=1` அவற்றை வரலாற்றில் வைத்திருக்கும்.
- **அறிவிப்புப் பயன்முறை** — `OPONS_VOXD_NOTIFY=normal|quiet|silent|off` வெற்றி அறிவிப்புகளைக் கட்டுப்படுத்தும் (இயல்புநிலை `quiet`: குமிழி மட்டும், ஒலி இல்லை). பிழைகள் எல்லாப் பயன்முறைகளிலும், விதிவிலக்கின்றி, எப்போதும் ஒலியுடன் காட்டப்படும். முழு அட்டவணைக்கு முதன்மை README-ஐப் பார்க்கவும்.
- **தானியங்கிப் பெரிய எழுத்து** — வாக்கியங்கள் தானாகவே பெரிய எழுத்தில் (capital) தொடங்கும்
- **தேவைப்படும்போது GPU-ஐ விடுவித்தல்** — Whisper மாடல்களை VRAM-இலிருந்து இறக்கி (ட்ரே மெனு மூலமோ, உள்ளமைந்த MCP சர்வர் வழியாக எந்த AI ஏஜென்ட் மூலமோ), வேலை முடிந்ததும் மீண்டும் ஏற்றலாம்
- **தானியங்கித் தொடக்கம்** — உள்நுழையும்போது தொடங்குமாறு அமைக்கலாம்

|---|---|---|
| xclip | X11 கிளிப்போர்டுகளுக்கு நகலெடுத்தல் | `sudo apt install xclip` |
| notify-send | டெஸ்க்டாப் அறிவிப்புகள் | `sudo apt install libnotify-bin` |

### NVIDIA GPU (விருப்பத்தேர்வு, ஆனால் செயல்திறனுக்கு மிக அவசியம்)

CUDA இல்லாமல், 15 வினாடி பேச்சுக்கு **10–15 வினாடிகள்** செயலாக்க நேரத்தை எதிர்பார்க்கவும். CUDA உடன், **1 வினாடிக்கும் குறைவு**. அதாவது **10–50 மடங்கு** வேகம்.

| கூறு | குறைந்தபட்சம் | சரிபார்ப்பு |
|---|---|---|
| NVIDIA இயக்கி (driver) | 570+ | `nvidia-smi` |
| CUDA Toolkit | 12.0+ | `nvcc --version` |

`nvidia-smi` வேலை செய்து `nvcc` வேலை செய்யவில்லை என்றால், CUDA toolkit-ஐ நிறுவவும்:

```bash
sudo apt install nvidia-cuda-toolkit
```

`nvidia-smi` காட்டும் CUDA பதிப்பு `nvcc` காட்டும் பதிப்பைவிட **குறைவாக** இருந்தால், இயக்கியைப் புதுப்பிக்கவும்:

```bash
ubuntu-drivers devices
sudo apt install nvidia-driver-590
sudo reboot
```

## உள்ளூர் AI-க்காக GPU-ஐ விடுவித்தல் (MCP சர்வர்)

Whisper மாடல்கள் எப்போதும் GPU நினைவகத்திலேயே இருக்கும் (`large-v3-turbo` + `medium`-க்குச் சுமார் 3.8 GB). அந்த VRAM வேறொன்றுக்குத் தேவைப்படும்போது — உள்ளூர் LLM, பட மாடல், பயிற்சி ஓட்டம் — opons-voxd நிரலை மூடாமலேயே அவற்றை இறக்கி, பின்னர் மீண்டும் ஏற்ற முடியும். இறக்குவது இந்தச் செயல்முறையின் CUDA சூழலையும் (context) அழிப்பதால், opons-voxd `nvidia-smi`-இலிருந்து முழுமையாக மறைந்துவிடும் (0 MB VRAM). மாடல் கோப்புகள் இன்னும் page cache-இல் இருந்தால் மீண்டும் ஏற்ற ஒரு வினாடிக்கும் குறைவான நேரமே ஆகும்; இல்லையெனில் சில வினாடிகள்.

**ட்ரே ஐகான் நிலைகள்:**

| ஐகான் | நிலை |
|:---:|---|
| வெள்ளை வளையம் | மாடல்கள் ஏற்றப்பட்டுள்ளன, தயார் |
| நிரம்பிய சிவப்பு வட்டம் | பதிவு செய்கிறது |
| நிரம்பிய ஆரஞ்சு வட்டம் | படியெடுக்கிறது |
| குறுக்குக் கோடிட்ட சாம்பல் வளையம் (⊘) | மாடல்கள் இறக்கப்பட்டுள்ளன, GPU நினைவகம் விடுவிக்கப்பட்டது, டிக்டேஷன் முடக்கப்பட்டுள்ளது |
| முக்கால் வட்ட நீல வில் | மாடல்கள் மீண்டும் ஏற்றப்படுகின்றன |

மாடல்கள் இறக்கப்பட்டிருக்கும்போது, ஐகானைக் கிளிக் செய்தாலோ push-to-talk ஹாட்கீயை அழுத்தினாலோ பதிவுக்குப் பதிலாகப் பிழை அறிவிப்பு காட்டப்படும்.

**கைமுறையாக:** ட்ரே ஐகானில் வலது கிளிக் > *Unload models (free GPU memory)* (மாடல்களை இறக்கி GPU நினைவகத்தை விடுவித்தல்), பின்னர் *Reload models* (மாடல்களை மீண்டும் ஏற்றுதல்).

**AI ஏஜென்டிலிருந்து (MCP):** daemon-ஐ `-m` / `--mcp` உடன் தொடங்கவும் (இயல்பாக முடக்கப்பட்டுள்ளது). `make` கட்டளை `opons-voxd-mcp`-ஐயும் உருவாக்கும்; இது stdio வழியாக இயங்கும், libc-உடன் மட்டுமே இணைக்கப்பட்ட ஒரு [Model Context Protocol](https://modelcontextprotocol.io) சர்வர் (சுமார் 1.5 MB RAM). இது மூன்று கருவிகளை வழங்குகிறது: `unload_models`, `reload_models`, `get_status`. Claude Code உடன்:

```bash
claude mcp add --scope user opons-voxd -- /path/to/opons-voxd/opons-voxd-mcp
```

பிற கிளையன்ட்களில் பெரும்பாலானவை (Claude Desktop, Cursor, LM Studio...) இந்த JSON-ஐப் பயன்படுத்துகின்றன:

```json
{ "mcpServers": { "opons-voxd": { "command": "/path/to/opons-voxd/opons-voxd-mcp" } } }
```

முழு விவரங்கள் [முதன்மை README](../README.md#free-the-gpu-for-local-ai-mcp-server)-இல்.

## Push-to-talk ஹாட்கீ

திட்டத்துடன் வரும் `launch.sh`, `ctrl+alt+w` (AZERTY விசைப்பலகைக்குப் பரிந்துரைக்கப்படுகிறது) அல்லது `ctrl+alt+z` (QWERTY விசைப்பலகைக்குப் பரிந்துரைக்கப்படுகிறது) ஆகியவற்றைப் பயன்படுத்துகிறது. அந்த விசை `A`-க்கு அருகில் இருப்பதால், முழுச் சேர்க்கையையும் தட்டச்சு நிலையைக் குலைக்காமல் இடது கையால் மட்டுமே எட்டலாம் (சுண்டுவிரல் `Ctrl`-இல், கட்டைவிரல் `Alt`-இல், மோதிர விரல் அல்லது நடுவிரல் `W`/`Z`-இல்); மேலும் பெரும்பாலான டெஸ்க்டாப் சூழல்களில் இது இயல்பாக எதற்கும் ஒதுக்கப்படவில்லை. இதை `OPONS_VOXD_PTT_HOTKEY` மூலம் அமைக்கவும். முழு விவரங்கள் [முதன்மை README](../README.md#push-to-talk-hotkey)-இல்.
