# opons-voxd

> గమనిక: opons-voxd కు jakovius/voxd తో ఎలాంటి సంబంధం లేదు. ఈ పేరును స్వతంత్రంగానే ఎంచుకోవడం జరిగింది — `opons` = O. Pons (రచయిత), `voxd` = vox + daemon (లాటిన్/Unix సంప్రదాయం).

> **⚠ పాత వెర్షన్లతో అనుకూలతను ఉద్దేశపూర్వకంగానే వదులుకున్నాం.** ఈ ప్రాజెక్ట్ పేరు ఇంతకు ముందు `voice_in_linux`. పేరు మార్పు వల్ల బైనరీ పేరు, సోర్స్ ఫైల్ పేరు, ప్రతి ఎన్విరాన్‌మెంట్ వేరియబుల్ (`VOICE_IN_*` → `OPONS_VOXD_*`), రన్‌టైమ్‌లో `xdotool` పై ఆధారపడటం (దాని స్థానంలో ఇప్పుడు `libxtst-dev` ద్వారా XTest తో నేరుగా కీ ఈవెంట్‌లు సృష్టించబడతాయి) — ఇవన్నీ మారాయి. ప్రత్యామ్నాయ పేర్లు లేవు, క్రమంగా తొలగించే గడువూ లేదు — మీ లాంచ్ స్క్రిప్ట్‌లు, ఆటోస్టార్ట్ ఎంట్రీలు, `apt install` లైన్లను అప్‌డేట్ చేయండి.

**Linux కోసం లోకల్ స్పీచ్-టు-టెక్స్ట్ డిక్టేషన్ — మీ గొంతు మీ కంప్యూటర్ దాటి ఎప్పటికీ బయటకు వెళ్లదు.**

## ఎందుకు?

నా గొంతును మూడో పక్ష సర్వర్‌కు పంపకుండా, Linux లో ఏ అప్లికేషన్‌లోనైనా డిక్టేట్ చేసి టెక్స్ట్ రాయాలనుకున్నాను. నేను చూసిన ప్రతి పరిష్కారం — బ్రౌజర్ ఎక్స్‌టెన్షన్లు, క్లౌడ్ APIలు, SaaS ప్లాట్‌ఫామ్‌లు — ట్రాన్స్‌క్రిప్షన్ కోసం మీ ఆడియోను రిమోట్ సర్వర్లకు పంపుతుంది. అంటే మీరు పలికే ప్రతి మాటా ఇంటర్నెట్ గుండా ప్రయాణిస్తుంది: ఈమెయిళ్లు, రహస్య పత్రాలు, క్లయింట్ డేటా, వ్యక్తిగత నోట్స్ — అన్నీ.

ఈ ప్రాజెక్ట్ తేలికైన, పూర్తిగా లోకల్‌గా పనిచేసే ప్రత్యామ్నాయం. ఇది [whisper.cpp](https://github.com/ggerganov/whisper.cpp) ను ఉపయోగించి పూర్తిగా మీ కంప్యూటర్‌లోనే నడుస్తుంది; whisper.cpp అనేది OpenAI విడుదల చేసిన ఓపెన్-సోర్స్ స్పీచ్ రికగ్నిషన్ మోడల్ Whisper ను లోకల్‌గా నడిపే రన్‌టైమ్. మొదటి సెటప్ తర్వాత నెట్‌వర్క్ కనెక్షన్ అవసరం లేదు. ఏ డేటా కూడా మీ కంప్యూటర్ దాటి బయటకు వెళ్లదు.

AI సహాయంతో నిర్మించినది.

## పనిచేసే విధానం

డిక్టేట్ చేయడానికి రెండు మార్గాలు, రెండూ ఒకేసారి అందుబాటులో ఉంటాయి.

### ట్రే ఐకాన్ మోడ్ — క్లిక్‌తో ఆన్/ఆఫ్, క్లిప్‌బోర్డ్‌కు కాపీ

1. మీ సిస్టమ్ ట్రేలో ఒక చిన్న ఐకాన్ కనిపిస్తుంది
2. **ఎడమ క్లిక్** → రికార్డింగ్ మొదలవుతుంది (ఐకాన్ ఎరుపుగా మారుతుంది)
3. **మళ్ళీ ఎడమ క్లిక్** → రికార్డింగ్ ఆగుతుంది, Whisper ద్వారా ఆడియో లోకల్‌గానే ట్రాన్స్‌క్రైబ్ అవుతుంది
4. ట్రాన్స్‌క్రైబ్ అయిన టెక్స్ట్ ఆటోమేటిక్‌గా మీ క్లిప్‌బోర్డ్‌కు కాపీ అవుతుంది (X11 లోని రెండు సెలెక్షన్లకూ)
5. డెస్క్‌టాప్ నోటిఫికేషన్ ఆ టెక్స్ట్‌ను 10 సెకన్ల పాటు చూపిస్తుంది
6. `Ctrl+Shift+V`, `Shift+Insert` లేదా మిడిల్ క్లిక్‌తో ఎక్కడైనా పేస్ట్ చేయండి

ఐకాన్‌పై **కుడి క్లిక్** చేస్తే Toggle / Unload models / Reload models / Quit ఉన్న మెనూ వస్తుంది ([లోకల్ AI కోసం GPU ని ఖాళీ చేయడం](#లోకల్-ai-కోసం-gpu-ని-ఖాళీ-చేయడం-mcp-సర్వర్) చూడండి).

### Push-to-talk మోడ్ — హాట్‌కీని నొక్కి ఉంచడం, కర్సర్ వద్ద టైపింగ్

1. **`Ctrl+Shift+Space` ను నొక్కి ఉంచండి** → రికార్డింగ్ మొదలవుతుంది (ఐకాన్ ఎరుపుగా మారుతుంది)
2. **కీలను వదలండి** → రికార్డింగ్ ఆగుతుంది, ఆడియో ట్రాన్స్‌క్రైబ్ అవుతుంది
3. ట్రాన్స్‌క్రైబ్ అయిన టెక్స్ట్, ఫోకస్‌లో ఉన్న విండోలో **నేరుగా కీబోర్డ్ కర్సర్ వద్ద టైప్ అవుతుంది** (X11 XTest ఎక్స్‌టెన్షన్ ద్వారా)

హాట్‌కీని `OPONS_VOXD_PTT_HOTKEY` ద్వారా మార్చుకోవచ్చు. రెండో, స్వతంత్ర హాట్‌కీ (`OPONS_VOXD_PTT_TRANSLATE_HOTKEY`, డిఫాల్ట్ `ctrl+alt+t`) కూడా అలాగే పనిచేస్తుంది, కానీ దానికి బదులుగా ఇంగ్లీష్ అనువాదాన్ని టైప్ చేస్తుంది — [ప్రధాన README](../README.md#push-to-talk-and-translate-hotkey) చూడండి.

## ఫీచర్లు

- **100% లోకల్** — ఆడియో మీ CPU లేదా GPU పైనే ప్రాసెస్ అవుతుంది, ఎక్కడికీ పంపబడదు
- **GPU యాక్సిలరేషన్** — దాదాపు తక్షణ ట్రాన్స్‌క్రిప్షన్ కోసం NVIDIA CUDA సపోర్ట్
- **99 భాషలు** — OpenAI Whisper ఆధారంగా
- **తేలికైనది** — స్వచ్ఛమైన C, Python లేదు: daemon, దానితో పాటు libc తో మాత్రమే లింక్ అయిన ఐచ్ఛిక 25 KB MCP సర్వర్
- **సిస్టమ్ ట్రే ఇంటిగ్రేషన్** — టాస్క్‌బార్‌లో ఇబ్బంది పెట్టని ఐకాన్
- **Push-to-talk హాట్‌కీ** — రికార్డ్ చేయడానికి `Ctrl+Shift+Space` (మార్చుకోవచ్చు) ను నొక్కి ఉంచండి; వదలగానే ట్రాన్స్‌క్రిప్ట్ కీబోర్డ్ కర్సర్ వద్ద టైప్ అవుతుంది
- **Push-to-talk-మరియు-అనువాదం హాట్‌కీ** — విడిగా సెట్ చేసుకోగల రెండో హాట్‌కీ, మాటకు మాట ట్రాన్స్‌క్రిప్ట్‌కు బదులుగా మీ మాటల ఇంగ్లీష్ అనువాదాన్ని టైప్ చేస్తుంది
- **డ్యూయల్ క్లిప్‌బోర్డ్** — టెక్స్ట్ X11 లోని PRIMARY, CLIPBOARD అనే రెండు సెలెక్షన్లకూ వెళ్తుంది
- **డెస్క్‌టాప్ నోటిఫికేషన్లు** — ట్రాన్స్‌క్రైబ్ అయిన టెక్స్ట్ నోటిఫికేషన్‌గా కనిపిస్తుంది
- **వాయిస్ కమాండ్లు** — `commands/` లో ఒక్కో భాషకు ఒక కమాండ్ ఫైల్; ఇవి డిఫాల్ట్‌గా ఆఫ్‌లో ఉంటాయి (`OPONS_VOXD_COMMANDS=1`). `commands/xx.txt` సృష్టించి కొత్త భాషను చేర్చవచ్చు, మళ్ళీ కంపైల్ చేయాల్సిన అవసరం లేదు.
- **తాత్కాలిక నోటిఫికేషన్లు** — డిఫాల్ట్‌గా నోటిఫికేషన్లు కనిపించి, ఆ తర్వాత పూర్తిగా మాయమవుతాయి. `OPONS_VOXD_NOTIFY_PERSIST=1` వాటిని హిస్టరీలో ఉంచుతుంది.
- **నోటిఫికేషన్ మోడ్** — `OPONS_VOXD_NOTIFY=normal|quiet|silent|off` విజయ నోటిఫికేషన్లను నియంత్రిస్తుంది (డిఫాల్ట్ `quiet`: బబుల్ మాత్రమే, శబ్దం లేదు). ఎర్రర్లు మాత్రం ప్రతి మోడ్‌లోనూ, మినహాయింపు లేకుండా, ఎప్పుడూ శబ్దంతో కనిపిస్తాయి. పూర్తి పట్టిక కోసం ప్రధాన README చూడండి.
- **ఆటో-క్యాపిటలైజేషన్** — వాక్యాల మొదటి అక్షరం ఆటోమేటిక్‌గా క్యాపిటల్ అవుతుంది
- **అవసరమైనప్పుడు GPU ని ఖాళీ చేయడం** — Whisper మోడళ్లను VRAM నుంచి అన్‌లోడ్ చేసి (ట్రే మెనూ ద్వారా గానీ, అంతర్నిర్మిత MCP సర్వర్ ద్వారా ఏ AI ఏజెంట్ అయినా గానీ), పని పూర్తయ్యాక మళ్ళీ లోడ్ చేయవచ్చు
- **ఆటో-స్టార్ట్** — లాగిన్ అయినప్పుడు ప్రారంభమయ్యేలా సెట్ చేయవచ్చు

> `libportaudio-dev` అవసరం లేదు: బిల్డ్ ప్రక్రియ `portaudio.h` ను (`curl` ద్వారా, మొదటి `make` సమయంలో) తెచ్చుకుని నేరుగా `libportaudio.so.2` తో లింక్ అవుతుంది. వివరాలు [ప్రధాన README](../README.md#development-libraries-required) లో.

### రన్‌టైమ్ టూల్స్ (తప్పనిసరి)

| టూల్ | ఉపయోగం | ఇన్‌స్టాల్ |
|---|---|---|
| xclip | X11 క్లిప్‌బోర్డ్‌లకు కాపీ | `sudo apt install xclip` |
| notify-send | డెస్క్‌టాప్ నోటిఫికేషన్లు | `sudo apt install libnotify-bin` |

### NVIDIA GPU (ఐచ్ఛికం, కానీ పనితీరుకు అత్యంత కీలకం)

CUDA లేకుండా, 15 సెకన్ల మాటకు **10–15 సెకన్ల** ప్రాసెసింగ్ సమయం పడుతుందని ఆశించండి. CUDA తో, **1 సెకను కంటే తక్కువ**. అంటే **10–50 రెట్లు** వేగం.

| భాగం | కనిష్టం | తనిఖీ |
|---|---|---|
| NVIDIA డ్రైవర్ | 570+ | `nvidia-smi` |
| CUDA Toolkit | 12.0+ | `nvcc --version` |

`nvidia-smi` పనిచేసి `nvcc` పనిచేయకపోతే, CUDA toolkit ను ఇన్‌స్టాల్ చేయండి:

```bash
sudo apt install nvidia-cuda-toolkit
```

`nvidia-smi` చూపించే CUDA వెర్షన్ `nvcc` చూపించే వెర్షన్ కంటే **తక్కువగా** ఉంటే, డ్రైవర్‌ను అప్‌డేట్ చేయండి:

```bash
ubuntu-drivers devices
sudo apt install nvidia-driver-590
sudo reboot
```

## లోకల్ AI కోసం GPU ని ఖాళీ చేయడం (MCP సర్వర్)

Whisper మోడళ్లు ఎప్పుడూ GPU మెమరీలోనే ఉంటాయి (`large-v3-turbo` + `medium` కు సుమారు 3.8 GB). ఆ VRAM వేరే పనికి — లోకల్ LLM, ఇమేజ్ మోడల్, ట్రైనింగ్ రన్ — అవసరమైనప్పుడు, opons-voxd ప్రోగ్రామ్‌ను మూసివేయకుండానే వాటిని అన్‌లోడ్ చేసి, తర్వాత మళ్ళీ లోడ్ చేయగలదు. అన్‌లోడ్ చేయడం ఆ ప్రాసెస్‌కు చెందిన CUDA కాంటెక్స్ట్‌ను కూడా నాశనం చేస్తుంది, కాబట్టి opons-voxd `nvidia-smi` నుంచి పూర్తిగా కనిపించకుండా పోతుంది (0 MB VRAM). మోడల్ ఫైళ్లు ఇంకా page cache లో ఉంటే మళ్ళీ లోడ్ చేయడానికి ఒక సెకను కంటే తక్కువ పడుతుంది; లేకపోతే కొన్ని సెకన్లు.

**ట్రే ఐకాన్ స్థితులు:**

| ఐకాన్ | స్థితి |
|:---:|---|
| తెల్లని వలయం | మోడళ్లు లోడ్ అయ్యాయి, సిద్ధం |
| ఎరుపు రంగు నిండు వృత్తం | రికార్డింగ్ |
| నారింజ రంగు నిండు వృత్తం | ట్రాన్స్‌క్రైబ్ అవుతోంది |
| అడ్డగీత ఉన్న బూడిద రంగు వలయం (⊘) | మోడళ్లు అన్‌లోడ్ అయ్యాయి, GPU మెమరీ ఖాళీ అయింది, డిక్టేషన్ ఆఫ్‌లో ఉంది |
| నీలి రంగు ముప్పావు వంపు | మోడళ్లు మళ్ళీ లోడ్ అవుతున్నాయి |

మోడళ్లు అన్‌లోడ్ అయి ఉన్నప్పుడు, ఐకాన్‌పై క్లిక్ చేసినా లేదా push-to-talk హాట్‌కీ నొక్కినా రికార్డింగ్ బదులు ఎర్రర్ నోటిఫికేషన్ కనిపిస్తుంది.

**చేతితో:** ట్రే ఐకాన్‌పై కుడి క్లిక్ > *Unload models (free GPU memory)* (మోడళ్లను అన్‌లోడ్ చేసి GPU మెమరీని ఖాళీ చేయడం), తర్వాత *Reload models* (మోడళ్లను మళ్ళీ లోడ్ చేయడం).

**AI ఏజెంట్ నుంచి (MCP):** daemon ను `-m` / `--mcp` తో ప్రారంభించండి (డిఫాల్ట్‌గా ఆఫ్). `make` కమాండ్ `opons-voxd-mcp` ను కూడా బిల్డ్ చేస్తుంది; ఇది stdio ద్వారా పనిచేసే, libc తో మాత్రమే లింక్ అయిన [Model Context Protocol](https://modelcontextprotocol.io) సర్వర్ (సుమారు 1.5 MB RAM). ఇది మూడు టూల్స్ అందిస్తుంది: `unload_models`, `reload_models`, `get_status`. Claude Code తో:

```bash
claude mcp add --scope user opons-voxd -- /path/to/opons-voxd/opons-voxd-mcp
```

ఇతర క్లయింట్లలో చాలావరకు (Claude Desktop, Cursor, LM Studio...) ఈ JSON ను ఉపయోగిస్తాయి:

```json
{ "mcpServers": { "opons-voxd": { "command": "/path/to/opons-voxd/opons-voxd-mcp" } } }
```

పూర్తి వివరాలు [ప్రధాన README](../README.md#free-the-gpu-for-local-ai-mcp-server) లో.

## Push-to-talk హాట్‌కీ

ప్రాజెక్ట్‌తో వచ్చే `launch.sh` `ctrl+alt+w` (AZERTY కీబోర్డ్‌కు సిఫార్సు) లేదా `ctrl+alt+z` (QWERTY కీబోర్డ్‌కు సిఫార్సు) ను ఉపయోగిస్తుంది. ఆ కీ `A` పక్కనే ఉంటుంది, కాబట్టి టైపింగ్ భంగిమను మార్చకుండానే మొత్తం కాంబినేషన్‌ను ఎడమ చేతితోనే అందుకోవచ్చు (చిటికెన వేలు `Ctrl` పై, బొటనవేలు `Alt` పై, ఉంగరపు వేలు లేదా మధ్య వేలు `W`/`Z` పై); పైగా చాలా డెస్క్‌టాప్ ఎన్విరాన్‌మెంట్లలో ఇది డిఫాల్ట్‌గా దేనికీ కేటాయించబడలేదు. దీన్ని `OPONS_VOXD_PTT_HOTKEY` ద్వారా సెట్ చేయండి. పూర్తి వివరాలు [ప్రధాన README](../README.md#push-to-talk-hotkey) లో.
