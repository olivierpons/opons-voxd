నా మాతృభాష ఫ్రెంచ్, కానీ నా సాఫ్ట్‌వేర్ పనిలో చాలా భాగం — కమిట్ మెసేజ్‌లు, కోడ్ కామెంట్లు, GitHub issues, అంతర్జాతీయ బృందాలతో చాట్, డాక్యుమెంటేషన్ — ఇంగ్లీష్‌లోనే జరుగుతుంది. ఇంగ్లీష్‌ను ధారాళంగా టైప్ చేయడం కష్టం కాదు; మెదడులోని మిగతా భాగం మాతృభాషలో నడుస్తున్నప్పుడు ఇంగ్లీష్‌లో *ఆలోచించడమే* అసలైన అడ్డంకి. మీరే అనువదించుకోవాల్సిన అవసరం లేకపోతే, డిక్టేషన్ ఆ అడ్డంకిని పూర్తిగా తొలగిస్తుంది.

## సెటప్

నేను opons-voxd ను రెండు స్వతంత్ర push-to-talk హాట్‌కీలతో వాడతాను:

- **`Ctrl+Alt+W` — సాధారణ డిక్టేషన్.** దాన్ని నొక్కి ఉంచి, ఫ్రెంచ్‌లో మాట్లాడి, వదలగానే కర్సర్ వద్ద ఫ్రెంచ్ టెక్స్ట్ టైప్ అవుతుంది. నోట్స్, ఫ్రెంచ్ సహోద్యోగులతో చాట్ — ఫ్రెంచ్‌లోనే ఉండాల్సిన ప్రతిదానికీ.
- **`Ctrl+Alt+K` — డిక్టేషన్‌తో పాటు అనువాదం.** అదే చర్య, కానీ నేను ఫ్రెంచ్‌లో మాట్లాడితే కర్సర్ వద్ద *ఇంగ్లీష్* వస్తుంది. ఇంగ్లీష్ పాఠకుల కోసం రాసే ప్రతిదానికీ: కమిట్ మెసేజ్‌లు, PR వివరణలు, కోడ్ కామెంట్లు, GitHub issues, ఇంగ్లీష్ చాట్ ఛానెల్స్.

అనువాద సాధనంలోకి కాపీ-పేస్ట్ చేయడం లేదు, వేరే విండోకు మారడం లేదు, మళ్ళీ టైప్ చేయడం లేదు. నేను మాట్లాడతాను, నా కర్సర్ ఇప్పటికే ఉన్న చోటే ఇంగ్లీష్ కనిపిస్తుంది.

## ఒక్కటి కాకుండా రెండు హాట్‌కీలు ఎందుకు

ఆ పని కోసమే నిజంగా శిక్షణ పొందిన మోడల్‌తోనే అనువాదం బాగా పనిచేస్తుంది. రోజువారీ ఫ్రెంచ్ హాట్‌కీకి నేను `large-v3-turbo` వాడతాను, అది వేగంగా ఉంటుంది కాబట్టి — కానీ దాని అనువాద నాణ్యత తక్కువ, ఎందుకంటే దాన్ని అనువాదం కోసం కాకుండా ట్రాన్స్‌క్రిప్షన్ వేగం కోసం ఆప్టిమైజ్ చేశారు. అనువాద హాట్‌కీ మాత్రం సరిగ్గా అనువదించే రెండో మోడల్‌ను (`medium`) లోడ్ చేస్తుంది. రెండు మోడళ్లూ ఒకేసారి GPU మెమరీలో ఉంటాయి; కొన్ని GB కంటే ఎక్కువ ఖాళీ ఉన్న కార్డ్‌పై ఈ అదనపు ఖర్చు పెద్ద విషయమే కాదు. లోకల్ AI పని కోసం ఆ మెమరీ నాకు తిరిగి కావాల్సి వచ్చినప్పుడు, ఆ పనిని నడిపే ఏజెంట్ opons-voxd MCP సర్వర్ ద్వారా రెండు మోడళ్లనూ అన్‌లోడ్ చేసి, పని అయ్యాక మళ్ళీ లోడ్ చేస్తుంది; ఈలోగా ట్రే ఐకాన్ అడ్డగీత ఉన్న బూడిద రంగు వలయంగా మారుతుంది, దాంతో డిక్టేషన్ ఆఫ్‌లో ఉందని నాకు తెలుస్తుంది ([లోకల్ AI కోసం GPU ని ఖాళీ చేయడం](README.te.md#లోకల్-ai-కోసం-gpu-ని-ఖాళీ-చేయడం-mcp-సర్వర్) చూడండి).

## ప్రయత్నించి చూడండి

ఇది opons-voxd లో ఉండే సాధారణ కాన్ఫిగరేషనే — fork గానీ patch గానీ అవసరం లేదు. `OPONS_VOXD_PTT_HOTKEY`, `OPONS_VOXD_PTT_TRANSLATE_HOTKEY`, `OPONS_VOXD_TRANSLATE_MODEL`, `OPONS_VOXD_LANGUAGE` కోసం ప్రధాన README లోని [Configuration](../README.md#configuration), [Push-to-talk-and-translate hotkey](../README.md#push-to-talk-and-translate-hotkey) విభాగాలు చూడండి.

మీరు రోజూ ఇంగ్లీష్ కాకుండా వేరే భాష మాట్లాడుతూ, పని మాత్రం ఇంగ్లీష్‌లో చేస్తుంటే, ఈ ప్రాజెక్ట్‌లో మీకు అత్యంత ఉపయోగపడే ఫీచర్ బహుశా ఇదే.
